# 多账户架构

## 为什么账户要独立预算

不同账户通常是不同平台（券商 / 银行 / 第三方销售），资金**不能自由互调**。所以预算必须按账户隔离：A 账户的钱再多，也不能用来补 B 账户的缺口。

配置里每个账户有独立的：

- `total_capital`：该账户可用于定投的总资金
- `weekly_budget_base`：常规周预算
- `weekly_budget_cap`：估值极低时的周预算上限，一般取 base 的 2~2.5 倍

## 分配顺序

每个账户内部独立执行：

1. 该账户下的所有基金按估值分位从低到高排序
2. 依序分配本周预算，分位最低的先拿满理论额
3. 预算耗尽后，后面的标的本周拿 0

**不是平均分，也不是谁跌得狠买谁。** 分位低 = 历史上更便宜 = 优先。

## 重复暴露检查

同一 `index_code` 出现在多只基金上（例如 A 账户持有创业板联接 A、B 账户持有创业板联接 C），脚本会告警。

含义：两个账户在押同一个风险，实际暴露是两者之和，可能远超你以为的单一权重。

处理方式二选一：
- 合并到费率更低的一只（同一指数优先看总费率：管理 + 托管 + 销售服务）
- 保留两只但把 `pool` 合计控制在单指数目标上限内

## 账户间是否需要平衡

一般不需要。理由：不同账户的基金本来就不同，权重由各账户的资金池决定，而不是由市场表现决定。

**唯一需要平衡的情形**：某账户因为估值低消耗过快，资金池接近耗尽，而另一账户还有大量余额。此时不是调预算，而是检查是不是该账户的 `pool` 设得过小。

## 季度再平衡

每季度做一次，只看两件事：

1. **实际权重 vs 目标权重**偏离是否超过 10 个百分点
   - 偏离原因是市场涨跌 → 不动
   - 偏离原因是某只低位消耗太快 → 下调该只 `base_weekly`
2. **大额投入是否打乱了节奏**：检查有没有单笔超过 4 周额度的买入。有的话记下来，作为下季度的观察项

调 `base_weekly`，不调档位系数表。档位表是全局规则，不该为单只标的改。

## 与 fund-etf-review 的衔接

新基金进场前先走 fund-etf-review 做选品（同指数替代品、费率、A/C 类、场内场外通道），选定后再加入本 skill 的配置。

不要在定投执行阶段临时换标的——换标的等于重新选品，要走完整评估流程。
