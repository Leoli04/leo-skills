# Stock Analyzer · 个股分析（方法论 v2.3 落地版）

## Overview

用一个固定顺序的 10 步流水线回答四个问题，产出一份自包含的交互式 HTML 报告。

四个问题（顺序错一步，后面全部作废）：
1. **它赚的是什么钱？** 利润驱动还是估值驱动 —— 决定用哪把尺子
2. **现在贵不贵？** 跟自己历史分位比，不是跟跌幅比
3. **利润是真的吗？** 扣非、现金流、一次性、研发刚性
4. **谁在买、谁在卖？** 筹码结构决定「便宜」能不能兑现

三条铁律：
- **任何跨年度目标价，必须时间折现 + 概率加权。** 未做这两道处理的目标价，一律视为卖方营销材料。
- **任何结论必须附带下一个验证点（指标 + 阈值 + 时间窗）。** 没有验证点的结论是观点，不是分析。
- **买入成本是心理锚，市场不认。** 不以「回本」为决策依据。

## When to Use

- 「分析分众传媒」/「全面分析XX」/「XX的投资分析报告」
- 「XX股票怎么样」/「XX值得投资吗」/「XX能买吗」
- 「帮我看看XX的财务数据」/「XX的估值合理吗」/「XX为什么跌」
- 用户附带持仓（如「我持有3成仓，成本5.3元」）→ 追加仓位建议章节

## 使用顺序（不可颠倒）

| 步骤 | 名称 | 一句话判据 |
|---|---|---|
| 第 0 步 | 选对估值锚 | 先归类，再谈贵贱 |
| 第 1 步 | 价格位置 | 用分位，不用跌幅 |
| 第 2 步 | 盈利趋势 | 单季环比，双重拆解 |
| 第 3 步 | 盈利质量 | 剔干净还剩多少 |
| 第 4 步 | 资产负债表 | 亏损公司看净资产 |
| 第 5 步 | 行业横向 + 景气定位 | 看营收同比，不看亏损；赛道定五档（+2~−2） |
| 第 6 步 | 催化与事件传导 | 先验链条是否贯通 |
| 第 7 步 | 筹码与公司行为 | 便宜能不能兑现 |
| 第 8 步 | 估值与赔率 | 折现 + 概率加权 |
| 第 9 步 | 前奏态扫描 | 仅「找标的」时走 |
| 第 10 步 | 验证与退出 | 指标 + 阈值 + 时间窗 |

三种典型颠倒失败（用来自查是否跳步）：
1. 先算价再验形态 → 尺子错了，整个估值过程无意义
2. 先看筹码再验利润 → 把派发当吸筹
3. 先看跌幅再查分位 → 把下跌当便宜，忽略「PE 低是因为盈利在顶」

**横切层（不参与选股）**：`references/methodology.md` 第 04 节《周期股专章》、第 05 节《环境与传导》、第 08 节《技术面与时序》。周期类标的在第 0 步之后先走周期专章。技术面**只服务择时与风控**，不得用于选股或估值，不得由「跌破支撑」反推基本面变坏。

## Workflow

### Phase 0: 前置 · 口径确认（读表之前必做）

口径错了，后面所有比率都不可比，而且错得很隐蔽。逐条核对（全文见 `references/methodology.md` §02）：

| 陷阱 | 正确处理 |
|---|---|
| 会计政策切换（如百货总额法→净额法） | 跨年只有 ROE 与归母可直比；收入、毛利率一律不可直比 |
| A/H 双重上市 | 报表口径与股价口径分开算；A/H 溢价单独处理 |
| 上市公司 ≠ 集团体系 | 只用上市公司披露口径，集团数据仅作背景 |
| 权益法投资收益（如持股银行） | 报表照记利润，但**禁止**用于偿债/分红/回购能力测算 |
| 北交所代码 | 一律用新 920xxx 段 |
| 定增后 PB 下降 | 用摊薄后股本重算，同步看摊薄 EPS 与 PE |
| 分红率口径不一 | 用 DividendTTM 交叉验证；TTM 亏损标 `n.m.`，不得填 0 |
| 高股息标的前复权价失真 | 高股息标的禁用前复权价，改市值口径 |

### Phase 1: 第 0 步 · 选对估值锚（15 类形态）

同一家公司用错尺子，结论可以完全相反。**「禁用」一栏是硬约束** —— 用禁用的尺子得出的结论，无论多合理都不采纳。

| 资产形态 | 主锚 | 禁用 |
|---|---|---|
| 盈利稳定重资产 | ROE 校准 PB（戈登：合理 PB = ROE / r，r≈9%） | — |
| 轻资产 | 正常化 PE + DDM + FCF 收益率三法收敛 | PB |
| 成熟制造 + 高分红 | DDM + 正常化 PE + 股息率反推 | PB |
| 强周期 | PB + 单位指标（头均市值等）+ 周期先行指标 | PE（峰值利润的反向指标） |
| 再投资出海（CXO） | PE + 在手订单 + 产能爬坡；扣非占比验成色 | 股息率 / DDM |
| 资源周期 | 商品价格位置 + PE 分位 + 单位成本 + 量增 | 绝对 PE |
| 周期新材料 | 历史峰值盈利锚 + 三情景概率加权 | 一致预期远期 PE |
| 小盘成长 | PE + PS + 流动性折价 + 预测分歧度 | 单一盈利预测 |
| 薄利制造 / 出口链 | 终局 PE 折现 + 同业 PB/ROE 比值 + 净利率敏感性 | 同比增速、单一 PEG |
| 专业市场 / 园区运营 | 分部估值 + DDM + OCF 转正验证 | 并表 PE |
| 亏损期制造 / 军工电子 | PB 双视角 + 同业横向 + 订单节奏先行指标 | PE、一致预期远期 PE |
| 银行 | PB ÷ ROE 匹配度 + 股息率 + 资产质量 | 单看 PB、PE |
| 寿险 | P/EV 主锚 + EV 驱动拆解 + 假设敏感性 | PE |
| 未盈利创新药 | 管线 rNPV + 每股净现金 + 现金跑道 + 关键读出 | PE / PB / PS |
| IP / 潮玩 | IP 瀑布拆解 + 存货周转 + 二手价 + 跨周期同业 PB 锚 | TTM PE、新 IP 同比 |

表外形态：先回答「它的价值由什么现金流决定」，再选锚。
「强周期 / 资源周期 / 周期新材料」三类不是拿到 PB 就能用 —— 须先做周期定位（走周期专章）。

**周期股专章（做周期标的必读，`references/methodology.md` §04）**
- 先分**周期型 vs 结构型**，判据只有一个：**价差回落时，利润还在不在**。周期型（价差驱动、单季跳升）走周期框架；结构型（连续 ≥3 年单向抬升）走第 9 步前奏门槛。同一标的可同时是两者。
- **定位五要素（缺一不可）**：价格位置（商品价十年分位）／供给端（在建工程÷固定资产、产能投放表、开工率）／需求端／库存天数及分位／成本曲线位置。**供给不配合，价格反弹一律按假复苏处理。**
- **四阶段 → 四把尺子**：底部（PB 分位 + 单位产能指标 + 重置成本，禁 PE）→ 复苏（正常化盈利 PE，**唯一可用 PE 的阶段**，禁用当期年化 PE）→ 顶部（上轮周期顶倍数 × 峰值盈利再折现，禁用低 PE 选股）→ 下行（现金成本覆盖 + 分红/OCF 支撑 + PB 底，禁用一致预期远期 PE）。
- **铁律**：① 周期股「PE 低」是卖出信号，不是买入信号，须先验分母能不能持续；② 峰值盈利越确定，应给倍数越低。
- **横向比较**用单位产能指标（头均市值 / 吨产能市值 / 桶油市值 / 单箱运力市值），绝对市值与绝对 PE 不可比。
- **退出：卖在景气，不在季报** —— 估值到位、供给重启、商品价 80% 分位以上、单位盈利连续两季转弱。禁用季报利润判断拐点（季报是滞后确认）。
- 「剔除周期行业」只作用于第 9 步前奏扫描，不等于「周期股不可买」。

### Phase 2: 第 1–7 步 · 七维尽调

用 WebSearch / 数据接口（见 `references/data_pipeline.md`）并行取数。每一步的「禁用」都是判定规则，不是提醒。

**第 1 步 · 价格位置（用分位，不用跌幅）**
- 用**前复权收盘价**自算近两年 / 近五年区间分位；记录横盘时长
- 标出关键高低点的**时间与成因**，区分「业绩顶」与「主题泡沫顶」（主题顶靠筹码出清，业绩顶靠利润回升）
- ✘ 禁用：把「跌了一半」当买入理由；「板块内最便宜」—— 相对便宜是陷阱

**第 2 步 · 盈利趋势（看单季环比，不看同比）**
- 年度 + 单季四条线同看：营收 / 归母 / 扣非 / 毛利率。高增长标的必做「半年环比 + 单季环比」双重拆解
- 核心判据：**连续两季营收同比与扣非同向恶化 ⇒ 未磨底**；季节性证伪必须用同一年度 Q2→Q3 环比，不能跨年比
- **毛利率抬升型必做结构改善净贡献（G2b）**：净贡献 = 毛利率同比 − 销售费用率同比 − 管理费用率同比，须四项同时满足：① > 0；② 营收同比不为负；③ 中高档/高端产品销量增速 ≥ 30%；④ 绝对毛利额同比为正
- 高基数的下一季是增速陷阱：先剔一次性收入，再问「主营增速还剩多少」

**第 3 步 · 盈利质量（剔干净还剩多少）**
- 扣非/归母比；一次性收入单独剔出，问「剔掉后主营增速还剩多少」
- 经营性现金流由正转负 = **质量硬伤**，必须与季节性拆开看
- **利润成色好 ≠ 经营未恶化**：扣非占比高 + 扣非增速低同时成立时，「成色好」恰说明经营性利润本身停滞
- **研发刚性陷阱**：研发投入 ≈ 毛利额时，即使订单恢复，利润弹性也被显著削弱
- 净利率 < 8% 的薄利公司，必做毛利率敏感性 + 汇兑敞口（毛利率降 1pct → 利润降约 14%）
- 政策主题要问落在哪个板块、毛利多少 —— **政策给收入不给利润率**

**第 4 步 · 资产负债表（尤其看亏损公司）**
- 有息负债变化、现金短债比、OCF 是否连续为负
- 亏损公司警惕「净资产缩水」制造**被动高估**的估值陷阱（分母自己变小）
- 「高分红 + 借款增 + 存货增 + 经营现金流为负」四并存需警惕 —— 但命中 2/4 不构成高危，须逐项核对

**第 5 步 · 行业横向 + 景气定位（判「行业性」还是「公司自身」，并定「赛道在周期的哪一档」）**

两件事必须同时做完：**横向比同业**、**纵向定景气**。只做横向会漏掉赛道方向 —— 同业都在涨可能是行业在景气上行，也可能是行业在集体反弹后一起回落。

*5a 行业横向（判「行业性」还是「公司自身」）*
- 同子板块取 ≥3 家 + 跨子板块取 ≥3 家对照
- 判决指标是**营收同比**，不是亏损绝对值。亏损收窄 / 营收转正 = 行业复苏已落地；亏损扩大且营收仍负 = 问题在自身
- 行业复苏但公司未跟上 ⇒ β 反弹拿不到，须下调至「恢复最慢」定价

*5b 景气定位（五档刻度，直接影响第 8 步的情景概率）*

把赛道当前位置定为 **+2 ~ −2 五档之一**。刻度、判据、对概率的作用方向：

| 档位 | 名称 | 判据（须挂可查先行指标） | 对情景概率的作用 |
|---|---|---|---|
| **+2** | 繁荣 | 量价齐升 / 供不应求 / 产能满载 / 行业利润创新高 | 乐观概率上调，但**这是卖出区不是买入区** |
| **+1** | 复苏 | 需求回暖 / 价格企稳回升 / 开工率上行 / 同业营收同比转正 | 乐观概率上调 |
| **0** | 平稳 | 供需大体平衡，无明确方向性驱动 | **不作行业调整**（基准态，公司 α 主导） |
| **−1** | 放缓 | 增速放缓 / 价格见顶 / 库存天数抬升 / 新增产能开始投放 | 中性略偏悲观（利好兑现即退出） |
| **−2** | 衰退 | 需求收缩 / 价格下行 / 产能出清未完成 / 公司营收仍负 | 悲观概率上调（是否见底看**供给端**配合） |

先行指标（按行业挂，每档至少能说出 1–2 个真实数字）：商品价十年分位 / 产能利用率 / 在建工程÷固定资产 / 库存天数及分位 / 同业营收同比 / 开工率。

两条防滥用规则（缺了刻度就退化成「编故事」）：
1. **每一档必须挂可查到的先行指标才算数** —— 说不出来一律判 0（平稳），不得凭印象给 +1/+2
2. **档位是「当前已发生的事实」，不是预测** —— 只描述现在处在哪，不预测未来会走到哪；预测交给第 8 步的情景概率本身

与周期专章的分工：第 0 步后的**周期专章**解决「产品价格处在周期什么位置、该用哪把尺子」；本步解决「**赛道整体景气在哪一档、该如何调整情景概率**」。两者结论必须一致，不一致时以周期专章为准（它更细）。

**第 6 步 · 催化与事件传导（先验链条，再看利好）**
- **宏观利好 ≠ 个股利好**。逐段验证「事件 → 行业 → 公司利润表」传导链，缺一段即证伪
- 核心是识别**身份错配**：收租方 / 平台方 / 渠道方 ≠ 交易方，收入由合同锁定、与行业景气脱钩。最有力的反证是「行业数据创新高而公司核心利润下滑」
- 利好必须定时滞。β 级利好不能对冲 α 级利空
- **时序证伪**：「事件前已有正面报道、事件日仍大跌」= 利好已被定价
- **已兑现的催化不追**（题材落地后连板、政策落地后放量均属兑现完成）
- 催化窗口要求 **6–12 个月内可见**，更远的只可跟踪不可作买入理由

**第 7 步 · 筹码与公司行为（便宜能不能兑现）**
- **筹码四件套同看**：主动基金家数、股东户数、北向持股、ETF 是否退出十大流通股东
- ⚠️ 股东户数下降不能直接读作「筹码集中」：须查年报「**披露日前一个月末**」户数，识别主题期涌入的散户余量
- 被动 ETF 增减持 = 指数编制与申赎，**不构成主动看多**
- 产业资本减持价只证明「减持价偏贵」，不证明「现价便宜」，**不可反推买点**
- **公司回购三查**：① 注销（真增厚每股价值）还是库存股（可再卖出，价值中性）；② 资金来源 —— 自由现金流回购 = 股东回报，借款回购 = 加杠杆托股价；③ 回购价所处估值分位 —— 高位回购是向卖方输送价值。回购与分红**不得重复计入**股东回报，分母一律用摊薄后股本
- **利好消息密度峰值 + 股价滞涨 = 派发特征**（配合主动基金家数减少）
- 卖方评级与买方持仓背离时，**信后者**
- 流动性是双侧约束：自由流通 < 30 亿流动性差，> 100 亿则少量资金无法定价。须显式说明用的是哪一侧

### Phase 3: 第 8 步 · 估值与赔率（把结论算成一个价）

**① 分位指纹（先看病灶在哪）**

| PE 分位 | PB 分位 | 读法 |
|---|---|---|
| 低 | 低 | 真便宜 —— 继续查基本面是否在恶化 |
| 低 | 高 | 盈利在顶 —— PE 低是假象 |
| 高 | 低 | 盈利与股价双底 —— 周期反转候选 |
| 99%+ | ≈0% | 盈利崩塌 —— 教科书级陷阱 |

- **双窗口必做**：同看「近两年分位」与「十年/全历史分位」，背离时**以十年为准**。只看近两年会把「PE 低 + PB 高 = 盈利在顶」误判为便宜
- 亏损公司无 PE，只看 PB 分位；轻资产公司 PB 分位只跟自己历史比，不跨行业比

**② 折现 + 概率加权（唯一合法的目标价算法）**

```
折现价 = 目标市值 / (1 + WACC)^n      // n 为年数，WACC 常用 12%
期望价 = Σ(情景价 × 情景概率)          // 概率之和必须 = 100%
```

- **买入门槛：期望价 / 现价 ≥ +15%**。达不到就是「不买」，而不是「有点空间可以试试」
- 即便完全接受卖方最乐观假设并折现，若结果 ≈ 现价 → 现价无安全边际
- 时间折现的实战校验：卖方目标价常是「某年利润 × 某倍 PE」**未折现**，补折现（WACC 12%，3 年因子 0.712）后往往 ≈ 现价，安全边际归零

**② 附一 · WACC 敏感性表（必做）** —— 期望价对折现率高度敏感，不给敏感性表，「现价溢价 / 折价 X%」这句表述立不住。做法：列 WACC 从基准 −3pct 到 +3pct（至少 5 档）的三情景折现价、加权期望价、对现价涨跌，然后**分两层下结论**：

| 层次 | 要回答的问题 | 小商品城实例 |
|---|---|---|
| 结论是否稳健 | 换 WACC 后「买不买」会变吗 | WACC 9% 时期望价 11.42（+3.10%），仍不过 +15% 门槛 → **不买结论稳健** |
| 表述是否敏感 | 「现价溢价 X%」这句换 WACC 还成立吗 | WACC 12% 时 −4.96%（溢价），**10% 时 +0.32%（基本平价）、9% 时 +3.10%（转折价）** → 表述敏感，必须标注 |

**判据**：若「溢价 / 折价」这类方向性表述对 WACC 敏感，**必须在正文标注敏感性**（不能只说基准档的结论）；若「买不买」的结论对 WACC 不敏感，则明确写「不依赖参数选择」，反而增强结论可信度。

**② 附二 · 股本摊薄闭环进目标价（存在摊薄事件时必做）** —— 增发 / H 股 / 可转债 / 大额股权激励等一旦落地，分母变大，**三情景折现价与期望价必须按摊薄后股本重算，并写进期望价盒**，不得只作定性风险提示。做法：给出「现股本 vs 摊薄后股本」两列对照表。

小商品城实例：风险节已列 H 股摊薄，但三情景按现股本 54.84 亿股算。补算摊薄后（60.93 亿股）：中性折现价 10.57 → **9.51 元**、期望价 10.53 → **9.48 元**（对现价 **−14.5%**，摊薄前为 −4.96%）—— **方向强化「不买」而非削弱**。摊薄比例须注明口径（本例按市场普遍预期的发行后总股本），实际规模待定则说明影响相应缩小。

**② 附三 · 分部估值兑现（自称「禁用并表 PE」时必做，否则口径声明即虚设）** —— 若报告在 Phase 1 判定某公司「必须分部看、禁用并表 PE」（典型：低毛利贸易业务拉低并表质量），那么**目标价也必须用分部口径算出并列出**，不能一边宣称分部、一边用「并表归母 × 单一 PE」定目标市值。**这是最隐蔽的自我矛盾**：口径声明在最前面，估值算式在最后面，两者相隔数千字，读者不易察觉，脚本也抓不到。

做法（4 列即可，5 分钟能算完）：

| 列 | 内容 |
|---|---|
| 分部 | 按业务性质归类（收租资产 / 服务 / 一次性项目 / 过手贸易），**不要照抄会计分部** |
| 归母化年化利润 | 分部利润 × 归母占比（= 归母净利 ÷ 分部利润合计），消除少数股东影响 |
| 给倍数 | 按现金流可预测性给——**一次性项目必须给 0–5x 或直接不给** |
| 对应市值 | 各行加总，与现市值、三情景目标市值三者并排 |

**三条纪律**：
1. **一次性项目绝不给经常性倍数** —— 房产结转、资产处置这类项目，给 0–5x；若给经常性倍数（如 15x），等于把一次性利润资本化，是「PE 低 = 便宜」陷阱的分部版本
2. **必须写清本表不含成长** —— 它用当期年化，与三情景的若干年后口径不可直接比较；它的用途是「给现价做横截面校验」，不是替代折现
3. **结论要落到「变强还是变弱」** —— 分部口径算完后，明确写出它对原结论的影响方向

小商品城实例：报告自称分部估值，三情景却用「2028E 归母 62.6 亿 × 13x = 814 亿」（并表口径）。补做分部估值：收租资产（年化归母 25.45 亿 × 15–20x）+ 贸易服务（5.47 亿 × 15–18x）+ 房产结转（8.58 亿 × 0–5x，一次性）= **464–650 亿（中位 557 亿）**，**低于现市值 607.58 亿**，更远低于并表中性情景 814 亿。反向推算：现市值剥离服务与房产后，隐含收租资产倍数 18.3–20.7x，**已高于收租资产合理区间上沿**。**结论：换分部口径后不是变弱、而是变强** —— 并表法把 0.83% 毛利率的过手贸易也计入了利润基数，变相给了它估值。同时，这张表顺带把悲观情景的触发路径写实了（房产结转归零 + 收租倍数回落 + 服务停滞）。

**② 附 · 卖方目标价三面检验（引用卖方目标价时必做，否则不得写进报告）**

卖方目标价是报告里最容易被读者误读的数字 —— 一个未折现的 19.84 元配上现价 11.08 元，读者第一反应就是「涨 79%，很便宜」。**必须做三面检验，三面结果都要写进报告**：

| 检验 | 做法 | 不做的后果 |
|---|---|---|
| **① 折现后可比** | 名义目标价 × 折现因子（12% / 3 年 = 0.7118），得出与现价**同口径**的可比价 | 读者拿未折现价与现价直接比，安全边际被系统性放大 |
| **② 多平台口径交叉** | 至少取 2–3 个来源（富途 / 腾讯舆情 / 近期券商研报原文），列出口径差异 | 单一来源可能是最高值，制造「便宜感」；口径分歧本身就是信息 |
| **③ 与自身情景对照** | 把折现后的卖方区间，与自己的三情景折现价并排摆 | 看不出「卖方最乐观 ≈ 我方乐观」，误以为卖方比自己乐观 |

**三个必须写出的结论（缺一即不完整）**：
1. **折现后的卖方区间 vs 现价** —— 名义 +79% 折现后往往只剩 +13%~27%
2. **卖方目标价高，通常高在 PE 倍数而非盈利预测** —— 若券商自己的盈利预测与你的中性情景接近，就必须点明「倍数分歧」才是真正的分歧点；若券商用「公司历史估值均值」定倍数，要追问该均值是否形成于盈利低位（是则方向反了）
3. **卖方评级系统性偏乐观的行业事实**（可选但强烈建议）—— A 股研报 90%+ 给「买入/增持」，卖出评级近零；A 股券商目标价 6 个月后平均偏离实际股价约 32%、12 个月约 47%。**目标价应读作「卖方立场声明」，不是价格预测**

**同时必须检查卖方动向**：近 3–6 个月是「上调预测」还是「下调预测但维持评级」。若券商在下调盈利预测的同时维持「强推/增持」且目标价下移，说明**评级已滞后于其自身模型** —— 报告用的若是「过去 12 个月均值」，就已滞后于这轮下调。

**②b 当前买入胜率（必做，三情景的衍生结果）**

期望价回答「平均能赚多少」，**胜率回答「这一把赢面多大」**。两者缺一不可 —— 高期望价可以完全由低概率 + 极端情景撑起，那不是胜率，是彩票。概率加权已给出所需的全部输入，必须顺手把胜率算出来。

**定义：胜率 = 满足「情景价 ≥ 现价 × 1.15」的情景概率之和。** 门槛沿用 +15% 买入尺子，保持全流程一致。

⚠️ **门槛是「≥ 现价 × 1.15」，不是「涨了就算赢」。** 情景相对现价上涨但涨幅不足 +15% 的，**不计入胜率**。这是最容易算错的一步 —— 若误按「正收益即算赢」统计，胜率会被系统性高估，把「不买」的结论翻转成「可买」。

**②c 行业景气 → 情景概率的联动（不做 = 默认行业永远中性）**

三情景概率**不得只由公司自身基本面推出**。第 5b 步定出的景气档位是概率的**前置输入**，必须显式落到概率分配上。

| 景气档位 | 对概率的作用 | 上限 |
|---|---|---|
| +2 繁荣 | 乐观概率上调 | 单情景 ≤ +10pct |
| +1 复苏 | 乐观概率上调 | 单情景 ≤ +10pct |
| 0 平稳 | 不作调整（基准态） | — |
| −1 放缓 | 悲观或中性概率上调 | 单情景 ≤ +10pct |
| −2 衰退 | 悲观概率上调 | 单情景 ≤ +10pct |

硬约束：
- **单情景调整幅度上限 ±10pct** —— 防止把行业叙事当成赌注加倍器
- **必须写明调整依据**：哪一档、挂的是哪个先行指标、调了哪个情景几个百分点。「行业不错所以调高乐观」不是依据
- **必须复盘原始概率**：报告里要能看到「公司自身基本面 → 基准概率」，再看到「叠加景气调整 → 最终概率」，两步分开写，读者能复核
- **+1/+2 不等于买入**：景气高位（+2）时乐观概率可以上调，但**估值分位若已高，仍是卖出区**。概率上调只改变期望值，不改变「贵」这个事实

**三档判定：**

| 胜率 | 判定 | 动作 |
|---|---|---|
| **≥ 50%** | 高胜率 —— 即便按最可能的中性情景也算得过来 | 达到期望价/现价门槛即可分批建仓 |
| **30% – 50%** | 中等偏博弈 —— 需要乐观情景才能赢，靠赔率补 | 只在期望价 / 现价 ≥ +25% 时介入，且首仓减半 |
| **< 30%** | 低胜率 —— 典型「赌重估」 | **不买**。与买入门槛判定独立，任一不过即否决 |

**期望价与胜率的关系（用于校准，不是替代）：**

```
期望价 / 现价 − 1 ≥ 胜率 × 乐观收益率 − (1 − 胜率) × 悲观损失率
```

期望价高但胜率低 ⇒ 期望靠尾部情景撑起 ⇒ 提高赔率要求或直接用仓位控制。**不能说「期望价够高所以胜率不重要」。**

**必写的四句话**（缺一句即视为未测算）：
1. 三情景的价格、概率、概率之和 = 100%
2. **景气档位 = ?（+2~−2）**，挂的先行指标是什么，概率因此调了多少
3. **胜率 = X%**（锁定门槛：情景价 ≥ 现价 × 1.15）
4. 胜率对应的仓位建议（高 / 中 / 低三档）

**与风控的接口**：胜率 < 30% 时，即便决定小仓位参与，也须按「跳空 −25%~−30%」定价仓位，使单一标的组合冲击 ≤ 1.5% —— 低胜率标的的仓位不是「多少合适」，而是「能不能承受归零」。

**禁止**：用「机构一致预期偏乐观」这类定性表述代替胜率数字；三情景概率必须显式列出，不得以「一般认为」代替。

**③ 赔率与风控**
- **R/R 分子禁用「合理价值上沿」（循环论证）**，取「最近有效阻力 ÷ 止损位」。分子分母都必须是从价格图上读出的数字
- 有效阻力识别：**筹码密集区**（前期成交额最大的价格带，最硬）> 前高/前低 > 整数关口（不得单独作阻力）。有效性判据 = 该位置附近**是否出现过放量滞涨**
- **止损位 ≠ 保证成交价**：可跳空标的的硬止损属假性风控
- **正解 = 以仓位为第一风控**：按跳空 −25%~−30% 定价，使单一标的组合冲击 ≤ 1.5%，用「事件前主动减仓」替代「事件后止损」
- 同等期望回报下，永远选「**可跟踪的风险**」（连续型下行优于二元型下行）
- A/H 溢价按部分收敛 haircut −20%~−25% 计入目标价；H 股 IPO 价是发行折价 ≠ 内在价值，递表本身即压制 A 股估值中枢
- 终值威胁分层采纳：不进当期 EPS，但**封顶退出倍数**

### Phase 4: 第 9 步 · 前奏态扫描（仅「找标的」时走）

首要判据：**市值倍数 ÷ 利润倍数** > 1 是赚估值的钱（叙事定价，安全边际框架不适用），< 1 才是赚利润的钱。

**前奏态六道门槛（权威定义，须照抄不得简写）**

| 门槛 | 定义 |
|---|---|
| G1 | 归母增速 ÷ 收入增速 ≥ 3x，且两者同为正 |
| G1b | 归母增速绝对值 ≥ 15%（防分母过小） |
| G2 | 毛利率同比 ≥ +2pct |
| G2b | 毛利率同比 − 销售费用率同比 − 管理费用率同比 > 0，且营收同比不为负，且中高档/高端产品销量增速 ≥ 30%，且绝对毛利额同比为正 |
| G3 | PE、PB 历史分位双 < 30%（近两年窗口判定 + 全历史窗口校验背离） |
| G4 | 自由流通 ≤ 100 亿 |
| 附加 | 上年同期归母 ≥ 1.2 亿、扣非/归母 ≥ 70%、市值 ≥ 30 亿、剔除周期行业 |

- 真假反差判别：**真 = 结构改善**（连续三年单向抬升）；**假 = 周期修复**（价差/加工差驱动，单季跳升）。利润增幅榜前几名往往是假的
- 4 条结构性共性：① 起点被行业叙事判过死刑；② 出现单位盈利能力更高的新市场；③ 报表反差；④ 筹码空白
- 两条最容易犯的错：① 股价滞后基本面 6–12 个月，启动前常有一次最后下跌；② 能搜到的一律已进入定价 ⇒ **必须框架驱动扫描，不能新闻驱动**

### Phase 5: 第 10 步 · 验证与退出（闭环）

**① 验证点：指标 + 阈值 + 时间窗，三要素缺一不可。** 要写成「可判真假的一句话」，不写「关注三季度业绩」。

**② 退出判据：四类触发，事先写死**

| 类型 | 触发条件 |
|---|---|
| 估值到位 | 触及概率加权目标价上沿 → 分批减 1/3 ~ 1/2 |
| 逻辑破坏 | 支撑买入的核心变量被证伪 → 不问盈亏直接退出 |
| 价格破位 | 跌破事先定义的关键低点 → 加速减 / 清仓 |
| 时间止损 | 约定窗口内未兑现催化 → 重新评估占用成本 |

**③ 减仓时机优先于止损价位**：事件前主动减仓 > 事件后止损。可跳空事件（反垄断、商誉减值、H 股发行、解禁、业绩说明会、转债到期、质押）执行「事件前减 1/3–1/2」。**时间炸弹要列成清单并前置**，这些是可提前排期的减仓时点，不是新闻。

**④ 成本锚定效应（实战中最烧钱的一条）**：正确表述是「折现期望价 X < 成本 Y → 数学上不支持死等回本」，同时「期望价对现价仅 +Z%，低于 +15% 买入尺子 → 不构成加仓」。两个结论各自独立，都由现价与期望价得出，与成本无关。

### Phase 6: 专项口径（命中行业时必读）

- **创新药**：单品高增长必拆「销量 × 价格」，价格跌幅 > 70% 即为以价换量；集采风险三触发（同靶点获批 ≥ 8 款 / 入基药目录 / 该代际渗透率 > 85%）；rNPV 参数：已获批 100% × 70% 商业化折扣、NDA 75%（补资料 ×80%）、III 期 60%、I 期 10%、稳态净利率 20%、成熟 PE 22x、WACC 12%
- **银行**：核心指标 PB/ROE 比值（农商行中位锚 0.0517）；**破净 ≠ 便宜**，必看 PB 历史分位；PE 分位 99.9% + PB 分位 0% = 盈利崩塌
- **农产品**：分三层（全球 vs 中国常反向 / 分品种 / 当期 vs 滞后）；厄尔尼诺年大豆单产可能 +5%（反直觉）；库存使用比阈值美玉米 11%；生猪能繁存栏须用 PSY 折算实际供给

4. **市场情绪** — 分析师评级与覆盖数、**卖方目标价三面检验拆解卡（折现后可比价 / 多平台口径 / 与自身情景对照 / 卖方动向）**、目标价区间**双系列图（名义价 vs 折现后）**、情绪环图、**资金进出趋势（分区间净额汇总表 + 柱图：今日 / 近 3 / 5 / 10 / 20 日与主力/北向对照）**、近期新闻时间轴（含情绪标签）、**信息密度与股价滞涨的派发判别**
5. **行业与竞品** — **行业景气定位卡（五档 +2~−2 + 先行指标表 + 对情景概率的作用方向）**、市占率对比、营收对比图、**同业营收同比对照表（判行业性 vs 自身）**、战略总结
6. **估值与健康** — 估值指标卡（PE TTM、前瞻 PE、PB、股息率）、**PE/PB 双窗口分位表（近两年 vs 全历史）**、**估值分位四象限图**、**三情景概率加权卡（悲观/中性/乐观 + 概率 + 期望价 + 买入门槛）**、**当前买入胜率与胜率×赔率定位图**、财务健康仪表盘
7. **宏观环境** — 宏观概览卡、宏观风险传导气泡图（概率 × 影响）、**宏观传导矩阵（变量 / 通道 / 受损 / 受益 / 时滞）**、**传导链到利润表的落点（财务费用率、汇兑损益占比、出口收入占比）**、**身份错配审查**、大势仓位判断
8. **主要风险** — 风险矩阵气泡图、风险明细卡（含严重度标签）。**公司层面风险放这里，宏观/系统性风险放第 7 节**
9. **验证与退出** — 验证点清单表（指标 + 阈值 + 时间窗）、退出判据四类、时间炸弹/事件前减仓排期、成本锚定正误对照
10. **结论建议** — 三时间维度建议卡（短/中/长）、**当前买入胜率结论卡（胜率数字 + 三档判定 + 对应仓位）**、**前次同标的报告复盘（若工作区留有旧版；逐条对照旧判断与新修正，见 Phase 9.5 第 11 条）**、看多逻辑、看空逻辑、综合评分矩阵
11. **自检清单** — 逐项勾选状态（素材 73 项，报告按标的取用）（四态：`通过` / `未通过` / `需注意` / `不适用`，模板已内置中文图例）+ 红线与陷阱速查

**自检清单四态语义**（用中文显示，不得混用；`不适用` 必须写明理由）：
- `通过` —— 已检查且符合要求
- `未通过` —— 已检查但不符合要求。**结论为「不买 / 回避」时，判否项必须标 `未通过`**，不得全部标通过（Phase 9.5 第 8 条）
- `需注意` —— 存在问题但可接受，已加注说明
- `不适用` —— 本标的不涉及该项，须在同一行写明理由（如「非周期形态，无需定位五要素」）。**`不适用` 不是「没查」，是「确认不涉及」**，与 `通过` 严格区分

> 实现说明：模板 CSS 沿用 `ok` / `no` / `warn` / `notapp` 四个 class 名（机器可读），**但页面上渲染与展示的文案一律用中文**（通过 / 未通过 / 需注意 / 不适用），不得把 `ok`/`no`/`na` 这类英文缩写暴露给读者。

**结构硬约束**：11 个 `<div class="section">` 必须是 `<div class="content">` 的**直接子元素且彼此平级**。错位会让整节空白或泄漏到其他 tab —— 改完模板后必须按 Phase 9 第 16 项做浏览器实测。

**① 公司概况硬规则：营收结构与利润结构必须成对、合并为一张对比图**（模板已预置合并图 `structCompareChart`（分组柱）+ 分部明细表 + 结论卡）。

为什么是硬规则：单一营收结构图会**反向误导估值锚**。当公司存在「高营收低毛利」业务（自营贸易 / 代销 / 通道业务 / 大宗贸易）时，营收图让读者得出「这是一家贸易公司」的错误结论，进而误用 PS 或并表 PE。把利润柱子并排放在同一组横轴上，排序反差才能一眼证明为什么禁用某把尺子。

**② 市场情绪硬规则：卖方目标价不得以「未折现名义价」出现在显眼位置**（模板已预置「先看这里」拆解卡 + 双系列目标价图）。

为什么是硬规则：卖方目标价是**报告里最容易制造「便宜感」的数字**。把「目标价均值 19.84 元 / 较现价 +79.1%」放进顶部指标卡，读者的第一反应就是「暴涨空间巨大」—— 而这个数字既未折现、又常是多个平台里的最高值、还可能是「过去 12 个月均值」罢了。**这是一种结构性误导，不是数据错误**。

硬性要求（详见 Phase 3 ②附「卖方目标价三面检验」）：
- 顶部指标卡若出现卖方目标价，**必须同时显示折现后可比价**，不得只写名义价与「+XX%」涨幅
- 目标价图表用**双系列**（名义价 vs 折现后），视觉上把「被水冲掉的部分」显性化
- 报告必须有一段**显式拆解**：① 折现后可比价 ② 多平台口径差异（指出本报告取的是哪一版）③ 与自身情景的对照（卖方最乐观 vs 我方乐观）④ 卖方近期是上调还是下调预测
- 若卖方自己的盈利预测与本报告中性情景接近，**必须点明分歧在 PE 倍数而非盈利** —— 这才是真问题所在

**③ 看多逻辑清单里的卖方目标价**同样适用：引用时必须带折现口径注，不得裸写「机构目标价 XX 元」。

- 两个系列**同一维度、同一口径、同一时点**（分部 vs 分部，不能一个按行业一个按分部）
- **合并为一张分组柱状图**：横轴取两系列并集，营收柱与利润柱成对并排。营收统一用**蓝 `#4a90e2`**、利润统一用**红 `#e94560`**（**禁用灰色承载营收** —— 灰色对比度低且语义混淆，灰只留给「资本支出 / 中性区」这类次要系列）
- 对照表：分部 / 营收 / 营收占比 / 毛利率 / 利润 / 利润占比
- 结论必须写成一句可判真假的话，例如「收入靠卖货，利润靠收租」，并点明**禁用哪把尺子、理由来自这张图**
- 若公司业务单一（无高低毛利错配），两系列基本等高 —— 仍要出合并图，并在结论里写明「两者同形，不存在口径错配」，不得因为是单业务就省略

**数据填写硬规则**：
- 颜色遵循 A 股惯例：**涨 = 红 (#e94560)，跌 = 绿 (#00c853)**
- 金额单位统一用「亿」（A 股）
- 模板 CSS 已含所需类，**不要改动 CSS 结构**
- 模板中每个数字都必须替换为真实调研数据，图表数据集不得留占位值
- **零编造原则（硬约束）**：任何图表数据集必须是**实测值**。若某项数据未取到，有两种合法处理 —— ① 标注「未获取」并留空；② 换用确实取到的口径作图。**严禁**用「模拟日度」「按区间反推」「示意值」等伪数据填充图表 —— 一个假数据点会污染整张图的可信度，且读者默认图上每根柱都是真的。取数时先问「这个粒度我拿到了吗」，没拿到就降粒度，不要升粒度编数
- **Chart.js 必须内联，禁止 CDN 引用（硬约束）** —— 报告须是「离线单文件、零外部依赖」。模板 `assets/report_template.html` 已把 Chart.js v4.4.1（完整源码存于 `assets/chartjs-4.4.1.min.js`，MIT 协议）**内联在 `<script>` 标签中**，直接复制模板即得自包含报告。**若模板被替换或需更新 Chart.js 版本**，用同一方式内联：`<script>/* Chart.js vX.Y.Z (MIT) */ ...源码... </script>`。**验收标准**：`verify_report.py` 的「自包含性」项必须为 PASS（文件内不得出现 `cdnjs` / `cdn.` / `unpkg` 等外部引用），且浏览器断网模式（`context({ offline: true })`）下 14 张图全部渲染。

### Phase 8: 组合层面（用户提到组合 / 多标的时）

- **砍相关性，不砍数量**。每个风险篮子只留最强那只。判据：会不会因同一条消息一起跌

#### 第 16 项：HTML 结构完整性实测（不可跳过）

改过模板后**必须跑浏览器实测**，只数 `<div>` 总数会漏判 —— 一多一少会互相抵消成平衡，但结构已经错了。

```javascript
// ① 所有 .section 必须是 DIV.content 的直接子元素，且彼此平级
document.querySelectorAll('.section').forEach(s =>
  console.log(s.id, '<-', s.parentElement.tagName + '.' + s.parentElement.className));

// ② 逐个点击，量真实渲染高度（比「是否可见」更严格）
document.querySelectorAll('.nav-btn').forEach(b => {
  b.click();
  const s = [...document.querySelectorAll('.section')].find(x => getComputedStyle(x).display !== 'none');
  console.log(b.textContent, 'h=' + s.offsetHeight, 'textLen=' + s.innerText.length);

```

**判废信号**：任一 section `h=0`（内容存在但零高度 = 被嵌进了隐藏的兄弟节点）；或 `textLen` 明显偏大（吞了别的 section 的文本）。

### Phase 9.5: 报告内容回查（交付前必跑，也可用于回查既有报告）

Phase 9 的 16 项是「写的时候自己盯」；Phase 9.5 是「写完/拿到报告后，用另一套眼睛再抓一遍」。两者不可互相替代 —— 实践反复证明，**作者视角的检查全绿，读者视角仍能一眼看出矛盾**。

**触发场景**：① 每次生成报告后、`present_files` 之前；② 用户要求「查看/回查某份报告是否还有要补充的」。

#### 第一遍 · 机器可验（跑脚本，别手数）

```bash
python <skill>/assets/verify_report.py "<报告.html>" --skill-dir <skill>
```

脚本自动核：标签配平（div/ul/li/table/tr）、section 数 = 11、canvas 与 `new Chart` 配对且 ID 全被引用、**版本号统一**、**自检清单标题数 = 实际 `<li>` 数**、**红线/陷阱计数 = redlines.md 基准**、**买入门槛 = 现价 × 1.15**、**情景概率和 = 100%**、**加权期望价 = Σ(折现价 × 概率)**、期望价/现价判定、赔率写法唯一、残留占位符、来源口径标注、外部 CDN 依赖。

退出码 0 = 无 FAIL。FAIL 必须逐项修到 0 再交付。

> 脚本只验「算得对不对、数得对不对」。**选哪个锚、逻辑自洽与否，脚本验不了**，必须走进第二遍。

#### 第二遍 · 人工读（脚本验不了的 11 条，逐条确认）

1. **数字自相矛盾** —— 同一事实在正文 / 括注 / 图内标注 / JS 数据集四处是否一致。**真实事故**：某报告写「W29 单周净流出 9.29 亿元」，同段括注与图上标注却是「−6.45 亿元」，JS 数据实为 −6.4475 亿元 —— 9.29 是上一版残留。脚本抓不到正文散文里的旧数字，只能靠读。
2. **图表数据源与卡片口径冲突** —— 价格卡写「52 周高点 26.56 / 低点 9.26」（盘中价），价格图序列最高 24.14 / 最低 9.68（收盘价）。两者本可不矛盾，但**必须在报告里写明口径差异**，否则读者以为数据错了。任一「卡片写一个数、图里画另一个数」都要么统一、要么加口径注脚。
3. **同一实体多处样本不一致** —— 竞品页「PB 图 9 家、营收图 4 家、财务表 4 家、概况表 6 家」。样本差异可以是刻意的，但**必须加一段「样本口径说明」讲清为什么不同**，否则读者判定为数据打架。
4. **估值方法适用性是否穷举** —— 亏损期不只用禁 PE，还要显式说明 DCF（无正现金流可折）、PS（收入含低毛利业务时与价值脱钩）为何不适用。漏列 = 结论缺一块支撑。
5. **折现说明是否算对** —— 正文若写「若改用 N 年折现，期望价降至 X 元」，**必须手算验一遍**。真实事故：写「3 年折现 → 6.86 元」，实际应为 7.13 元（10.02 ÷ 1.12³）。
6. **折现价盒表述是否会引起误读** —— 「情景价 7.61 元 × 概率 28%（已折现 1.5 年）= 1.80 元」易被读成「先乘概率再折现」。正确写法：「**折现价 6.42 元 × 概率 28%**」，且六个数（三折现价 + 三概率）与上方进度条、下方胜率表同源。
7. **散文里提到的待办/进度是否与正文一致** —— 如「本章共 N 张图」「以下三项」这类计数句，逐个数一遍。
8. **自检清单的勾选状态是否与结论自洽** —— 结论「不买」时，相关项应是 `no` 而非 `ok`；只打勾不判否 = 清单走过场。
9. **读者视角通读（最容易被跳过、也最容易翻车的一条）** —— 上面 8 条都是「算得对不对」的实现层检查，**没有一条问「一个不懂本方法论的投资者读到这里，能不能读懂」**。必须换一双眼、按下面五个动作真读一遍：

   - **动作 1｜导出渲染文本再读**：跑 `assets/_reader.js`（playwright）导出报告**渲染后**的全文，不要读源码 —— 源码里有注释和 JSON 会掩盖真实阅读顺序。
   - **动作 2｜标记所有「读者没有的上下文」**：逐个扫这些词 —— `第 N 步`、`第 ⑤/⑥ 节`、`合法/禁用尺子`、`尺子`、`归类`、`形态`（指内部形态分类时）、`五要素`、`指纹`、`身份错配`、`时间炸弹`、`成本锚定`、`假性风控`、`红线`、`陷阱`、`Phase`、`流水线`、`references/`、`DividendTTM`、`15 类`、`近 N 期`。**出现即命中**，改为读者语言（对照表见 Phase 7）。
   - **动作 3｜标记所有「自证性文字」**：`非示意值`、`不列不估算`、`均为实测值`、`不是数据打架` 等 —— 这些是写给检查者看的自证，读者会觉得莫名其妙；能删则删，保留则改成对读者有信息量的口径说明。
   - **动作 4｜逐节问「这一节对投资者有什么用」**：每节读完，问自己「一个只想判断买不买的读者，读完这节获得了什么」。若某节只回答了方法论的自问自答，就是内部内容泄漏。
   - **动作 5｜结论页单独重读**：⑥⑩ 两节是投资者真正会复读的部分，**先在纸上写「我读完记住了哪三条」**，再看报告正文是否支持这三条；不支持的表述就是冗余或误导。

   > 判据：**作者视角全绿 ≠ 读者读得懂**。这条之所以单列，是因为它此前被当成主管审美而非硬规则，结果连续多轮由用户替我先发现 —— 现固化为必检项。

10. **「误导性内容」专项扫描（不是措辞问题，是数据与断言问题）** —— 上面 9 条处理「读不读得懂」，这条处理「读懂了但被带偏」。逐类扫：

    - **无依据的定性断言（双向）** —— 扫所有形容词：「租金水平仍显著低于市场价」「护城河极深」「品牌溢价强」。问一句「**和什么比？数据在哪？**」说不出就删或补数据。**看多与看空标准一致**。
    - **绝对数值全篇唯一** —— 把关键数字（仓位上限、门槛、目标价、概率、费率）全篇 grep 一遍，确认同一指标只有一个值。**真实事故**：仓位上限一处写「≤0.5%」、另一处写「≤5%」——两者相差 10 倍，且脚本抓不到。
    - **派生值必须给推导式** —— 由「单一标的冲击 ≤ 1.5%」推出的「仓位 ≤ 5%」，须写成 `1.5% ÷ 30% = 5%`，读者才能复核。
    - **定性打分须标性质** —— 护城河 / 综合评分这类主观分值，必须注明「定性判断，非客观数据」；分数方向不能与结论相反（若结论是「不买」，给「租金提价能力 80 分」就与「续租率可能下降」冲突）。
    - **比喻不能与事实冲突** —— 「最像债券的资产」与「OCF 转负」直接矛盾；比喻只可用于解释，不可用于美化。
    - **交叉引用指向读者认得的名字** —— 不用「第 ⑦ 节」这类编号（读者要翻回去数）。
    - **格式残留** —— `**星号**` 未解析、错字（如「见第 ⑦ 节商宏观环境」多出的「商」）、旧文案残留（如已合并为一张图却仍写「两张一起看」）。**另须扫 `<title>` 与页脚 / 版本号**：文件由别的标的报告复制改写时，标题最易漏改（真实事故：小商品城报告的 `<title>` 仍写着「分众传媒（002027）」）。
    - **PE / PB 口径必须反算验证** —— 同一时点行情软件并列给出动态 / 静态 / 另一口径三个 PE（本例：13.53 / 15.35 / 14.45），净利基数完全不同（44.91 / 39.58 / 42.05 亿）。**标注方法**：市值 ÷ PE = 隐含净利，与哪个口径对得上就叫哪个。**只叫错口径不叫错数** —— 13.53 的算法本身没错，错在标成 TTM。另须检查：分位取自 A 序列、绝对倍数取自 B 序列时，**不可并列比较**，必须显式区分。
    - **看多核心论据不得与别处结论互拆** —— 本例最严重的一处：用「含 12 亿一次性房产结转」的利润撑起「历史最低 PE 分位 → 便宜」，同时另一节论证「剔除一次性后经常性利润增速已停滞」。**这两段互相拆台**。凡属看多主论据的数字，都要问一句「这个数字与报告别处的哪句话可能冲突？」
    - **跨节数据一致性三查** —— ① **口径**：同一收入项在同比 / 环比两处分别出现时，须各自标注，防「一笔贡献两笔增量」；② **加总**：分部表加总 ≠ 并表总额时，差额须单列「其他 / 内部抵消」或注明未披露（本例差 1.99 亿）；③ **假设**：情景隐含增长率若高于正文论证的趋势（本例中性情景隐含 14.2% CAGR vs「扣非停滞」），必须正面拆解该情景由哪几块拼出。
    - **涨跌幅必须给基期** —— 凡写「某月跌 X%」「年初至今跌 X%」，须标明基期数值。**真实事故**：报告写「9 月 -11.22%」，基期是 8 月末收盘 12.48 元；但价格图上 9/1 点为 12.96 元，读者若以 9/1 为基期会算出 -14.51%，看起来像数据错误。
    - **百分比与展示值精度一致** —— 展示「13.2 万户 → 20.9 万户」时百分比必须按展示值复算（= +58.3%），而非沿用源数据未四舍五入的 +57.6%。**展示精度变了，衍生百分比要跟着变**。
    - **涨跌配色合规** —— A 股语境**涨 = 红、跌 = 绿**（与欧美相反）。首页指标卡、表格、图表一律照此；「归母净利 +36.8%」应用红，用绿即错。
    - **行业分类双口径须说明层级** —— 同一报告用两套行业分类时（如申万一级「一般零售 60 家」用于市值排名、申万三级「专业市场」用于同业对标），须说明二者是上下层级关系而非冲突分类，并各自标注用途。
    - **主观判断须标性质** —— 除护城河打分外，**三情景概率、胜率**同样属主观判断。若胜率在数学上等于某情景概率（如只有乐观情景达门槛时，胜率 = 乐观概率），必须说明其性质，避免读者误以为是市场隐含或统计测得的客观值。
    - **报告有效期注记** —— 页脚须写「本报告有效期至下一次定期报告披露」，并点名该报告会命中哪些验证点。财务分析有明确失效时点，不注明的报告在下次财报后就成误导。
    - **图表每个点位都要有来源或标「示意」** —— 逐个核对每张图的**数据集、参考点、分区锚点、阈值线**：来自实测的、在图注中点明；仅为「标明方位」的（如胜率图的「买入区 / 中性区」、四象限图的象限锚点），图例名须带「示意」二字且图注说明「非可比实测值」。**真实事故**：四象限图给同业点了「海宁皮城 5%/18%、轻纺城 40%/30%、中位 50%/45%」三个坐标，正文却无任何数据支撑，图注仍称「4 个真实点位」；胜率图的「买入区 / 中性区」两点同样无来源却作实测呈现。**若某张对比图除本公司外都拿不到实测数据，该图不成立，须删图或降维为只画本公司的单点图**。图注不得出现「均为真实点位」这类笼统自证。
    - **CSS 类完整性** —— HTML 里用到的每个 `class` 都要在 `<style>` 里有定义（跑 `verify_report.py` 的「CSS 类完整性」项）。**真实事故**：⑥ 节财务健康卡用 `.health-item/.hi-head/.health-bar/.health-fill/.hi-note`，而 `<style>` 里只有模板旧的 `.health-card/.hc-*` —— 5 个类全部未定义，卡片无边框底色、进度条 `height:0` 不显示，浏览器里一堆裸文字。**类名不匹配是静默失败**：源码、`div` 配平、渲染文本三处都看不出，只有浏览器里量 `getComputedStyle` 才暴露。**改过卡片 / 表格结构后必查**。
    - **差额的符号方向 + 比率的分母基准** —— ① 分部表差额**为正**（加总 < 并表）是「未分配的其他业务收入」，**为负**（加总 > 并表）才是「内部抵销」，两者不可共用一个标签。**真实事故**：差额 +1.99 亿却标为「其他 / 内部抵消」——方向和标签矛盾。② 比率类指标（摊薄比例 / 稀释 / 占比 / 涨幅）必须写明分子分母的基准：占「发行前」还是「发行后」、占「总资产」还是「股票仓位」。**真实事故**：H 股「摊薄比例 10%」实为「新股 ÷ 发行后总股本」（＝原股东权益摊薄 −10.00%），但易被读成「股本增加 10%」（实际 +11.11%）。写法：把分子分母都写出来，并补两种口径的换算。
    - **舍入风格统一（新增段落最易带进第二套）** —— 同一指标全篇必须用同一种舍入（截断或进位）。**真实事故**：中性折现价 `10.567`，旧文按截断写 `10.56`、**新加的两张表**按进位写 `10.57`；同类还有 `−4.9657%` 既写 `−4.96%` 又写 `−4.97%`。**成因固定：新增段落 / 表格最容易带入第二套舍入** —— 写完把该指标全篇 grep 一遍对齐。
    - **派生式与源数据表勾稽** —— 拆解式 / 推导式里**每一个被减数、除数**都要与它引用的那张源数据表逐一对上，且算出的比例与文中标注的比例自洽。**真实事故**：环比拆解写「46.93 → 56.89 亿」算出 +21.2%，而同表单季营收实为 **45.93**（45.93 → 56.89 ＝ +23.9%，才与标注的 +23.9% 自洽）—— 一个笔误的被减数就让拆解式与结论值直接打架。
    - **自算列整列复算 + 全列同分母 + 列标题即口径** —— 占比 / 增速 / 差值这类**由报告自行计算**的列，比引用来的数据更易错（引用有出处可核，自算没有）。**最隐蔽的错误不是算错一个数，而是同一列不同行悄悄换了分母** —— **真实事故**：某表「占比 2023→2025」列，2023 年「主营业务收入 = 营业总收入 = 112.81」两基数相等，2025 年「主营 192.61 ≠ 总营收 197.07（差 4.46 亿其他业务收入）」，原表 2025 各行用了总营收基数、2023 各行用了主营基数，导致 2025 占比被系统性低估 0.1–1.2pct（26.7 应为 27.3、50.7 应为 51.8、6.6 应为 6.8、9.9 应为 10.1）—— **基准年两基数恰等，掩盖了分母的存在**。另须查**列标题口径与单元格内容是否一致**：列标题写「占比 2023→2025」，单元格却填了 2024→2025 的增速（贸易服务行把 2024→2025 的 +138.6% 填进来，而 2023→2025 应为 +178%）。**执行方式**：每个自算列先写出分母是什么 → 逐行「分子 ÷ 分母」复算 → 表下明写该列分母口径。
    - **不照抄行情软件的 PE 字段名** —— 字段命名可能与惯例相反：本例腾讯行情把 `14.45x`（隐含 2025 年报归母 42.04 亿，**才是通常意义的静态 PE**）之外的字段标为「静态」。**以反算结果为准**，字段名与反算不符时在报告里点明「行情软件字段命名与惯例相反」；反算对不上任何口径时注明「口径未注明，疑为 XX，仅列示不采用」（本例 15.35x 隐含 39.58 亿，与 42.04 归母不符，疑为扣非）。
    - **计数虚报（声称的条目数 = 实际条目数）** —— 分两类数字，**各自的比对对象不同**，不可混用：① **文件内实际条目数** —— `redlines.md` 三处章节标题（`红线速查（60 条）` / `陷阱对照（49 个）` / `出清单前自检（73 项）`）与**模板清单标题**（`出清单前自检 · {{自检项数}} 项`）须等于各自文件内实际条目数；② **报告采用基准数** —— `redlines.md` 来源行「故为 X / Y / Z」，这是**报告应采用的项数**（红线/陷阱全量采用故与素材数相同，**自检按标的取用、可少于素材数**，如素材 73 项 / 报告取 67 项）。**报告自检清单标题**须等于**报告自身实际勾选条数**（= 第 ② 类的 Z），既非素材数也非随意填的数。**真实事故**：`redlines.md` 标题写「陷阱 40 个」而表内只有 39 行、写「自检 61 项」而清单只有 59 条 —— 与红线 54「自检虚报」同型。**计数虚报是最隐蔽的自检失效**：读者看到「已核 61 项」会直接关掉警惕，实际少核的部分无人发现。**执行方式**：每次增删条目后**用脚本回数**（`verify_report.py` 的「自检清单计数」+「自检项基准」两项 + 规则 `grep -c`），不靠记忆填标题。
    - **正文新增内容反向回写清单** —— 交付前若往正文补了新表 / 新数据 / 新卡片，必须回头确认**清单里有对应自检项**；反之亦须扫「清单里有、正文里定位不到」的虚报项（红线 54）。本轮的「分部三年趋势 / 商户侧第三方指标 / 股东结构 / 跨境平台竞争」四块新增内容，都要各有一条自检项与之对应。
    - **编辑既有 HTML 后必重跑标签配平** —— 增删 `<li>` 时极易连带吃掉或留下多余的 `<ul>` / `</ul>`。**真实事故**：删一条重复的自检项时误删了相邻的 `</ul>`，导致 `<ul>` 11 开 / 10 闭 —— 浏览器里仍能渲染（容错），但结构已坏且脚本会 FAIL。**改完跑 `verify_report.py` 的标签配平项**。
    - **并列布局的两栏内容量必须相当（`grid-2` 均衡）** —— `grid-2` 是 `1fr 1fr` 等宽栏，**两栏高度差过大即为排版事故**：一栏只有一张图、另一栏塞进 4 块内容（表格 + 深色盒 + 长文字），结果窄栏里的内容被压扁、宽栏里留大片空白。**真实事故**：估值节一个 `grid-2` 的右栏里叠加了「三情景进度条 + 折现加权盒 + 分部估值表 + 又一份折现盒」，左栏只有一张 PE 图 —— 读者一眼看出失衡。**修法不是调 CSS，而是重新分配容器**：把**宽表（≥5 列）、深色盒、长段落**从 `grid-2` 栏内提升为**独占整行**（`val-section` / `exp-price-box` 直接放 section 层级）；只把「一图 vs 一图」「一表 vs 一表」这类量级相当的内容留在 `grid-2` 里。**判否标准**：`grid-2` 内任一侧的垂直高度 > 另一侧 1.5 倍，或一侧含 ≥3 个独立块、另一侧只有 1 个。改完**必须截图或浏览器实跑量高度**，不靠脑补 —— 源码缩进与标签配平都看不出失衡。
    - **改结构时警惕「整块被复制」** —— 大段内容搬运（移动一个盒到别处）时，**先删原处还是先插新处极易搞反，导致同一块出现两次**。**真实事故**：把「折现 + 概率加权」盒从右栏移到整行时，新处已插入、原处未删，文档里同一份折现盒出现了两次，且标签仍配平、脚本仍 PASS（重复的 `<div>` 内部自洽）。**判否标准**：搬运后 grep 该块的唯一特征串（如 `class="exp-price-box"`），出现次数须为 1。

    > 这一条的出现顺序值得注意：**前 9 条都是「读者视角」，第 10 条是「对抗视角」，第 11 条是「时间视角」** —— 假定有人在用话术影响读者，逐句反问「这句话想让我相信什么？证据够吗？」；再假定有旧版报告躺在同一目录，反问「上次的判断这次翻案了没有？翻在哪个数上？」

11. **前次同标的报告的复盘对照（若工作区留有旧版，必做）** —— 同一标的若在本地留有更早的报告（如 `XXX_投资分析报告_<旧日期>.md/html`），**必须先读旧版再写新版**，并在新版⑩节加一段「前次判断复盘：这份报告推翻的是什么」。三种情形分别处理：

    - **旧结论与本次相反**（本例：旧版「偏低估、值得持有、11.5 元补仓」→ 本次「不买」）—— 必须**点名推翻的是哪一个数**，而不是笼统说「看法变了」。逐项列表：估值读数（旧「PE 分位 57%」→ 新「0.14%」，口径反差要解释清楚是谁错了）、目标价、关键经营指标（出租率 / 增速）、重大事件状态（H 股「已完成」→ 实为「已递交申请」）。**附「两版为什么差这么多」的归因**，否则读者会怀疑是同一份数据被两次解读成相反结论。
    - **旧结论与本次相同** —— 写「延续」并说明**新增了什么证据**使其更确定（新数据点 / 新事件 / 新增分部口径），避免读者以为只是复制粘贴。
    - **旧版存在事实错误** —— 明写「前版此处有误」（本例 H 股状态、PE 分位口径两处），**纠正而非沉默覆盖**。沉默覆盖会让同时看过两版的读者对全部数字失去信任。
    - 复盘段的硬要求：**旧值、新值、差异原因三列齐**；不得只写「已更新」，不得为维护前版面子而含糊其辞（见 Phase 7 第 10 节）。若确实无旧版，本节不写，但**交付说明里要提一句「工作区未发现同标的旧版报告」**，证明不是漏做。


#### 回查记录写入工作日志

每轮回查把「发现 → 修复」逐条记进当日 memory 日志（含错误原值、正确值、根因）。这些是 skill 与文档下一轮迭代的输入 —— 踩坑 1、2、6 都源于此。

### Phase 10: 可选 · 仓位建议

用户提供持仓时追加。结构：

```
持仓现状：成本价、现价、浮动盈亏%、仓位占比、成本对应 PE vs 市场 PE
操作建议：
```

## Important Notes

- **Phase 0 不能跳。** 口径确认是后面所有比率的可比性前提
- **第 0 步不能跳。** 用错尺子的分析，写得再漂亮也是废纸
- **并行取数**：Phase 2 的多次 WebSearch / 接口调用并行发起，缩短周转
- **周期标的有特殊路径**：第 0 步之后先走周期专章，不做定位就定不了锚
- **交付前必跑 Phase 9.5 第二遍的第 9 / 10 / 11 条** —— 第 9 条（读者视角通读）验「读不读得懂」，第 10 条（误导性内容专项扫描）验「读懂了有没有被带偏」，第 11 条（前次报告复盘对照）验「换没换过说法、翻案翻在哪个数上」。前 8 条都在验「算得对不对」。经验教训：这三条若跳过，内部工序术语、无依据断言与自相矛盾的数据会成批漏到读者面前，且每一轮都由用户先发现。
- **技术面只有两个合法用途**：确定买点区域、确定止损位与 R/R 分子
- **区分一次性与经常性**：财务章节必须说明利润变化是核心经营驱动还是一次性项目
- **估值偏保守**：近期有一次利润冲击时，用前瞻估计而非 TTM 数据
- **风险要具体到公司**：每条风险说明为什么对这门生意重要，不用通用模板
- **剔除理由禁用「超目标价 / 已分析过」**，须用估值分位或商业模式重述。候选池必须独立于覆盖进度
- **初筛结论必须显式声明「深度不足」**，不得与深度覆盖结论并列，不得作为加仓依据
- **无验证点不出结论；验证点未通过不加仓**
- **交付前必跑 Phase 9.5 回查**（脚本第一遍 + 人工读 11 条，见上）。作者视角检查全绿 ≠ 报告无矛盾
