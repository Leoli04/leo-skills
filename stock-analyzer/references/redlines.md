## 一 · 红线速查（50 条）

### 事件 · 传导与催化

1. **宏观利好 ≠ 个股利好。** 先验「事件 → 行业 → 公司利润表」传导链是否贯通；核心是识别身份错配 —— 收租方 / 平台方 / 渠道方 ≠ 交易方，收入由合同锁定、与行业景气脱钩。最有力的反证是「行业数据创新高而公司核心利润下滑」
2. 利好要定时滞；「事件前已有正面报道、事件日仍大跌」= 时序证伪，利好已被定价
3. **β 级利好不能对冲 α 级利空**
4. **已兑现的催化不追**；催化必须 6–12 个月内可见。更远的催化只可用于跟踪，不可作买入理由
5. 政策主题要问落在哪个板块、毛利多少 —— **政策给收入不给利润率**

### 估值与筛选

6. **PB 双视角必做**（近两年 vs 十年 / 全历史），**背离时以十年为准**
7. **低 PE 必须先验「分母能不能持续」** —— 盈利在顶时 PE 低是假象
8. **峰值利润 PE 是反向指标**；周期顶估值锚 = 上轮周期顶市场给的倍数，峰值盈利越确定应给倍数越低
9. 判断贵贱**三维同看**：年内涨幅 + PE/PB 分位 + 同业横向。「跌了一半」不是买入理由，「板块内最便宜」是相对陷阱
10. **筛选标准全流程一致**：换标准须显式说明并重排；剔除理由禁用「超目标价 / 已分析过」，须用估值分位或商业模式重述。候选池独立于覆盖进度
11. **跨年度目标价必须折现 + 概率加权**，折现因子 1/(1+WACC)^n
12. **终值威胁分层采纳**：不进当期 EPS，但封顶退出倍数

### 周期与位置

13. **周期股「PE 低」是卖出信号，不是买入信号**；「PE 高 / 为负 + PB 分位低」才是周期反转候选，但仍须先过供给要素
14. **周期定位五要素（价格 / 供给 / 需求 / 库存 / 成本曲线）缺一不可**；供给端不配合时，价格反弹一律按假复苏处理 —— 价格反弹 ≠ 产能出清
15. **周期与结构必须分开归因**：价差驱动 = 周期修复（假反差，须剔出前奏候选）；判据是「价差回落时利润还在不在」
16. **「剔除周期行业」只作用于第 9 步前奏态扫描**，不适用于已覆盖周期标的的分析，也不等于「周期股不可买」
17. 周期股横向比较用**单位产能指标**（头均市值 / 吨产能市值 / 桶油市值 / 单箱运力市值），绝对市值与绝对 PE 不可比，且须与 PB 分位同看
18. **周期股卖在景气**：估值到位 / 供给重启（在建工程回升、新产能公告密集）/ 商品价进 80% 分位以上 / 单位盈利连续两季转弱；**禁用季报利润判断周期拐点**（季报是滞后确认）

### 环境 · 大势与技术

19. **宏观变量没有普适符号** —— 同一变量对不同行业符号相反；使用前必须分流分子 / 分母，并给出强度与时滞。「利率升 → 股价跌」这类单链等于没分析
20. **无法落到利润表的宏观判断，不得作为买入理由**；传导结论须落到可跟踪指标（财务费用率 / 汇兑损益占利润比 / 出口收入占比…）
21. **大势只调仓位，不替代个股尽调** —— 不得因「大盘要涨」买入未过尺子的标的
22. **技术分析只服务择时与风控**（买点区域、止损位、R/R 分子）；不得用于选股或估值，不得由「跌破支撑」反推基本面变坏
23. **行业景气必须定位到档（+2~−2），且每一档须挂可查先行指标**。说不出来一律判 0（平稳），不得凭印象给 +1/+2；档位只描述**当前已发生的事实**，不预测未来路径。**景气判断不得直接等同于买入理由** —— 它只调整情景概率，不改变估值分位这个主锚

### 盈利质量

24. **高增长必做「半年环比 + 单季环比」双重拆解**；季节性证伪用同一年度 Q2→Q3 环比
25. **净利率 < 8% 必做毛利率敏感性 + 汇兑敞口**（毛利率降 1pct → 利润降约 14%）
26. **经营现金流由正转负是质量硬伤**，须与季节性拆开
27. **一次性收入单独剔出**，问「剔掉后主营增速还剩多少」；**高基数的下一季是增速陷阱**
28. **利润成色好 ≠ 经营未恶化**：扣非占比高 + 扣非增速低同时成立时，「成色好」恰说明经营性利润本身停滞
29. **研发刚性陷阱**：研发 ≈ 毛利额时，订单恢复也换不来利润弹性

### 筹码与交易

30. **减持价只证明「减持价偏贵」，不证明「现价便宜」**，不可反推买点。减持从来不是买入信号
31. **筹码四件套同看**；**股东户数下降 ≠ 筹码集中**（须查年报「披露日前一个月末」户数）
32. **被动 ETF 增减持 = 指数编制与申赎**，不构成主动看多
33. **R/R 分子禁用「合理价值上沿」**（循环论证），取「最近有效阻力 ÷ 止损位」
34. **止损位 ≠ 保证成交价**；**以仓位为第一风控**，单一标的组合冲击 ≤ 1.5%
35. **同等期望回报下，永远选「可跟踪的风险」** —— 连续型下行优于二元型下行
36. **利好消息密度峰值 + 股价滞涨 = 派发特征**；筹码判断必须落到可查数据（基金家数 / 股东户数 / 北向 / 龙虎榜），**禁用「庄家吸筹 / 主力洗盘」等不可验证叙事**

### 跨境与口径

37. **A/H 溢价按部分收敛 haircut −20% ~ −25% 计入目标价**；H 股 IPO 价是发行折价 / 清算价 ≠ 内在价值；H 股递表本身即压制 A 股估值中枢，不必等发行
38. **港股必做汇率校验**：财报双口径倒推汇率，归母 × 汇率 ≈ 接口值
39. **关键数字必须标来源 + 时点 + 口径**；口径不可比时禁用比率（见 `methodology.md` §02 的 10 条口径陷阱）

### 前奏识别

40. **市值倍数 ÷ 利润倍数 > 1 是赚估值的钱**（叙事定价，安全边际框架不适用），< 1 才是赚利润的钱
41. **必须框架驱动扫描，不能新闻驱动**；「报表反差」须分辨真假（结构改善 vs 周期修复）；已排除方向与「出海 ≠ 前奏」见第 9 步

### 持仓与交付纪律

42. **买入成本是心理锚，市场不认。** 不以「回本」为决策依据。成本价本身不产生支撑 —— 产生支撑的是全体持有者的成本分布
43. **初筛结论必须显式声明「深度不足」**，不得与深度覆盖结论并列
44. **无验证点不出结论；验证点未通过不加仓**
45. **报告是给投资者的，不是给方法论执行者的** —— 方法论对分析的约束（步骤号 / 「合法尺子·禁用尺子」/ 判据术语 / 内部文件引用）不得原样写进报告正文，须翻译成读者能懂的业务语言。**禁用**引用读者拿不到的 `references/*.md`，禁用「红线 / 陷阱 / Phase / 流水线」这类内部计数与工序词。**执行方式**：交付前必跑 Phase 9.5 第二遍第 9 条（读者视角通读五动作 —— 导出渲染文本 → 扫内部工序词 → 扫自证性文字 → 逐节问「对投资者有什么用」→ 结论页单独重读）。**判否标准**：扫出任意一个内部工序词或自证性文字即为未通过
46. **卖方目标价不得以「未折现名义价」出现在显眼位置** —— 卖方目标价是报告里最容易制造「便宜感」的数字，把「均值 X 元 / 较现价 +YY%」放进顶部指标卡属结构性误导（非数据错误）。引用时必须：① 同时显示折现后可比价 ② 列出至少 2 个平台的读数并说明本报告取的是哪一版 ③ 与自身三情景折现价并排对照 ④ 检查卖方近期是上调还是下调预测。**若卖方自己的盈利预测与你的中性情景接近，必须点明分歧在 PE 倍数而非盈利预测** —— 这才是真分歧。评级与目标价应读作「卖方立场声明」，不是价格预测
47. **看多方向的定性断言必须挂数据，否则删除** —— 「租金水平仍显著低于市场价」「品牌溢价能力强」「护城河极深」这类**无对比基准的定性断言**，会单方面抬高读者的价值感，且无法被证伪。凡属看多方向（支撑「值这个价」）的定性表述，要么给出可查数据与对比基准，要么删除。**看空方向的定性表述同样处理** —— 双向适用，标准一致。**自检方法**：把每个形容词问一遍「和什么比？数据在哪？」
48. **正文中所有绝对数值必须全篇唯一且自洽** —— 同一指标在报告不同位置出现两个不同数字即为 FAIL（如仓位上限一处写「≤0.5%」、另一处写「≤5%」）。**特别注意派生值**：由「单一标的冲击 ≤ X%」推导的仓位上限，必须写出推导式（如 1.5% ÷ 30% = 5%），使读者可复核。**这些数字不在 verify_report.py 的自动检查范围内，必须人工逐项比对**
49. **PE 的口径必须反算验证后才能标注** —— 行情软件同一时点会并列给出动态 / 静态 / 另一口径三个 PE，对应净利基数完全不同（本例：动态 13.53 / 静态 15.35 / 另一 14.45，隐含净利 44.91 / 39.58 / 42.05 亿）。**标注方法**：市值 ÷ PE = 隐含净利，与哪个口径的利润对得上就叫哪个。**若采用动态口径，必须额外说明其是否含一次性项目** —— 动态 PE 的隐含利润含大额一次性结转时，不得据此得出「历史最低分位 → 便宜」，因为同一份报告别处正在论证该利润不可持续，两段会互相拆台。**分位（相对位置）与绝对倍数分属不同口径体系，不可并列比较** —— 分位可用，倍数不可
50. **跨节数据的一致性三查** —— ① **口径一致性**：同一指标在不同节的对比基准（同比 / 环比）必须分别标注，防「一个项目贡献两笔增量」的误读。② **加总一致性**：任何分部 / 分项表，加总须等于并表总额；差额须单列「其他 / 内部抵消」或注明未披露，不得留白。③ **假设一致性**：情景假设隐含的增长率若与报告别处的趋势论断冲突（如中性情景隐含 14% CAGR，而正文论证经常性增速已停滞），必须正面拆解该情景由哪几块拼出，不能留缝。**这三查不在自动脚本范围内，属交付前人工必做**

## 二 · 陷阱对照（34 个）

| 陷阱 | 正解 |
|---|---|
| 把「跌了一半」当买入理由 | 参照系是公司自己的历史估值分位，不是跌幅 |
| 用近两年 PB 分位判低估 | 必须同时看十年 / 全历史分位（近两年中枢可能被主题行情抬高） |
| 把股东户数下降读作「筹码集中」 | 查年报「披露日前一个月末」户数，识别主题期涌入的散户余量 |
| 用产业资本减持价反推买点 | 减持价只证明「该价偏贵」，不证明「现价便宜」 |
| 引用卖方远期 PE 目标价 | 必须折现；净利率为负的公司给 50x+ PE 本身不成立 |
| **把卖方目标价的「较现价 +XX%」直接当上涨空间** | 卖方目标价未折现，且常是多个平台里的最高值。必须过三面检验：折现后可比价 / 多平台口径交叉 / 与自身情景对照。折现后往往只剩 +13%~27% |
| **只看卖方目标价、不看卖方动向** | 若券商在下调盈利预测的同时维持「强推/增持」且目标价下移，评级已滞后于其自身模型；报告若用「过去 12 个月均值」就滞后于这轮下调 |
| 用 PE 给亏损公司估值 | 只看 PB 分位，并注意净资产缩水导致的「被动高估」 |
| 把 ETF 增持当主动看多 | 被动资金反映指数编制与申赎 |
| 忽略研发刚性 | 研发 ≈ 毛利额时，订单恢复也换不来利润弹性 |
| 用毛利率抬升直接推利润改善 | 先过 G2b 四项条件（含营收同比不为负、绝对毛利额同比为正） |
| 把买入成本当价值锚 | 成本不影响期望价；「回本」不是持有理由，用「期望价 ÷ 现价」重判 |
| 追已兑现的催化 | 要「催化未兑现」；题材落地后连板 / 政策落地后放量均属兑现完成 |
| 用「行业数据创新高」推个股利好 | 先验身份是否错配（收租方 / 渠道方收入由合同锁定，与行业景气脱钩） |
| 把初筛结论当深度结论 | 无完整覆盖必须显式声明「初筛，深度不足」，且不得作为加仓依据 |
| 忽略流动性下限与组合容量 | 自由流通过小则进出成本高、过大则无法被资金定价；须写明用的是哪一侧约束 |
| 用低 PE 选周期股 | 周期顶 PE 最低。改看 PB 分位 + 「上轮周期顶倍数 × 峰值盈利」再折现 |
| 把价格反弹当周期反转 | 先验供给是否出清（在建工程 ÷ 固定资产、开工率、库存天数）；供给不出清，一律按假复苏处理 |
| 用当期年化盈利给周期股估值 | 用中周期均价做正常化盈利再折现；底部、顶部、下行三段均禁用 PE |
| 把「剔除周期行业」误读为「周期股不可买」 | 该规则只作用于第 9 步前奏扫描，防价格修复型利润跳升污染 G1 / G2b |
| 「营业收入增加 → 股价上涨」/「盈利增加 → 股价自然上涨」 | 线性外推。须做单季环比双拆解、剔一次性、验扣非成色，并警惕高基数的下一季是增速陷阱 |
| 「利率上升 → 股价下跌」单链 | 未分流分子 / 分母、未给强度与时滞；同一变量对不同行业符号相反 |
| 由「跌破支撑线」反推基本面变坏 | 技术面只服务择时与风控；基本面变坏须由报表与传导链证明 |
| 「有主力吸筹 / 庄家在洗盘」 | 不可验证叙事。筹码判断须落到基金家数 / 股东户数 / 北向 / 龙虎榜 |
| 「公司回购 = 利好」 | 须查注销 vs 库存股、资金来源（自由现金 vs 借款）、回购价所处估值分位 |
| 「利好消息密集 → 买入」 | 信息密度峰值常是派发窗口；须看股价是否滞涨 + 筹码是否迁移（基金家数 / 户数） |
| 只看期望价、不算胜率 | 期望价可由「低概率 + 极端情景」单方面撑起。须同时给出胜率（情景价 ≥ 现价 × 1.15 的概率之和）与三档判定；胜率 < 30% 与期望价不达标**各自独立否决** |
| 用「机构一致预期偏乐观」代替胜率数字 | 定性表述不是测算。三情景价格、概率、概率之和 100% 必须显式列出 |
| 只做行业横向、不定位行业景气 | 同业一起涨可能是行业景气上行，也可能只是集体反弹后一起回落。须纵向定五档（+2~−2）并喂给情景概率 |
| 「行业不错 → 调高乐观概率」 | 无先行指标的景气判断无效。每一档必须挂可查指标（价格分位 / 产能利用率 / 库存天数 / 同业营收同比），说不出来一律判 0 |
| 把行情软件的**动态 PE** 标成 TTM / 扣非 | 同一时点行情软件常并列给出动态 / 静态 / 另一口径三个 PE，三者对应的净利基数完全不同。**标口径前必须反算验证**：市值 ÷ PE = 隐含净利，与哪个口径的净利润对得上就叫哪个。**动态 PE 含当期一次性项目时，不得据此得出「极低分位 → 便宜」** —— 一次性项目撑起来的高利润会压低 PE，与「该利润不可持续」的论断互相拆台。**分位可用于相对位置，绝对倍数不可跨口径并列比较** |
| 把同一笔一次性收入同时算作「同比增量」与「环比驱动」 | 同一收入项在不同对比基准（同比 vs 环比）下会各出现一次，读者易误读为「一个项目贡献了两笔增量」。两处必须分别标注口径（同比 / 环比），并说明是同一收入项的两种呈现 |
| 分部营收加总 ≠ 并表总营收而不作说明 | 分部表按业务线列示，通常不含「其他 / 内部抵消」项。加总后与并表总额的差额必须单列一行或显式注明「未单独披露、不作估算」，否则读者自行加总会对不上，进而怀疑全表数据 |
| 情景假设的隐含增速与自身风险论述打架 | 若中性 / 乐观情景隐含的 CAGR 明显高于报告别处论证的「经常性增速已停滞」，必须**正面拆解该情景由哪几块拼出**（经常性增长 + 已签约项目结转 + 新业务减亏），并说明不依赖经常性利润加速。否则情景假设与风险论述之间存在未弥合的缝 |
