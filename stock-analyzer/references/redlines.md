## 一 · 红线速查（43 条）

### 事件 · 传导与催化

1. **宏观利好 ≠ 个股利好。** 先验「事件 → 行业 → 公司利润表」传导链是否贯通；核心是识别身份错配 —— 收租方 / 平台方 / 渠道方 ≠ 交易方，收入由合同锁定、与行业景气脱钩。最有力的反证是「行业数据创新高而公司核心利润下滑」
2. 利好要定时滞；「事件前已有正面报道、事件日仍大跌」= 时序证伪，利好已被定价
3. **β 级利好不能对冲 α 级利空**
4. **已兑现的催化不追**；催化必须 6–12 个月内可见。更远的催化只可用于跟踪，不可作买入理由
5. 政策主题要问落在哪个板块、毛利多少 —— **政策给收入不给利润率**

### 估值与筛选

6. **PB 双视角必做**（近两年 vs 十年 / 全历史），**背离时以十年为准**
7. **低 PE 必须先验「分母能不能持续」** —— 盈利在顶时 PE 低是假象
8. **峰值利润 PE 是反向指标**；周期顶估值锚 = 上轮周期顶市场给的倍数，峰值盈利越确定应给倍数越低
9. 判断贵贱**三维同看**：年内涨幅 + PE/PB 分位 + 同业横向。「跌了一半」不是买入理由，「板块内最便宜」是相对陷阱
10. **筛选标准全流程一致**：换标准须显式说明并重排；剔除理由禁用「超目标价 / 已分析过」，须用估值分位或商业模式重述。候选池独立于覆盖进度
11. **跨年度目标价必须折现 + 概率加权**，折现因子 1/(1+WACC)^n
12. **终值威胁分层采纳**：不进当期 EPS，但封顶退出倍数

### 周期与位置

13. **周期股「PE 低」是卖出信号，不是买入信号**；「PE 高 / 为负 + PB 分位低」才是周期反转候选，但仍须先过供给要素
14. **周期定位五要素（价格 / 供给 / 需求 / 库存 / 成本曲线）缺一不可**；供给端不配合时，价格反弹一律按假复苏处理 —— 价格反弹 ≠ 产能出清
15. **周期与结构必须分开归因**：价差驱动 = 周期修复（假反差，须剔出前奏候选）；判据是「价差回落时利润还在不在」
16. **「剔除周期行业」只作用于第 9 步前奏态扫描**，不适用于已覆盖周期标的的分析，也不等于「周期股不可买」
17. 周期股横向比较用**单位产能指标**（头均市值 / 吨产能市值 / 桶油市值 / 单箱运力市值），绝对市值与绝对 PE 不可比，且须与 PB 分位同看
18. **周期股卖在景气**：估值到位 / 供给重启（在建工程回升、新产能公告密集）/ 商品价进 80% 分位以上 / 单位盈利连续两季转弱；**禁用季报利润判断周期拐点**（季报是滞后确认）

### 环境 · 大势与技术

19. **宏观变量没有普适符号** —— 同一变量对不同行业符号相反；使用前必须分流分子 / 分母，并给出强度与时滞。「利率升 → 股价跌」这类单链等于没分析
20. **无法落到利润表的宏观判断，不得作为买入理由**；传导结论须落到可跟踪指标（财务费用率 / 汇兑损益占利润比 / 出口收入占比…）
21. **大势只调仓位，不替代个股尽调** —— 不得因「大盘要涨」买入未过尺子的标的
22. **技术分析只服务择时与风控**（买点区域、止损位、R/R 分子）；不得用于选股或估值，不得由「跌破支撑」反推基本面变坏

### 盈利质量

23. **高增长必做「半年环比 + 单季环比」双重拆解**；季节性证伪用同一年度 Q2→Q3 环比
24. **净利率 < 8% 必做毛利率敏感性 + 汇兑敞口**（毛利率降 1pct → 利润降约 14%）
25. **经营现金流由正转负是质量硬伤**，须与季节性拆开
26. **一次性收入单独剔出**，问「剔掉后主营增速还剩多少」；**高基数的下一季是增速陷阱**
27. **利润成色好 ≠ 经营未恶化**：扣非占比高 + 扣非增速低同时成立时，「成色好」恰说明经营性利润本身停滞
28. **研发刚性陷阱**：研发 ≈ 毛利额时，订单恢复也换不来利润弹性

### 筹码与交易

29. **减持价只证明「减持价偏贵」，不证明「现价便宜」**，不可反推买点。减持从来不是买入信号
30. **筹码四件套同看**；**股东户数下降 ≠ 筹码集中**（须查年报「披露日前一个月末」户数）
31. **被动 ETF 增减持 = 指数编制与申赎**，不构成主动看多
32. **R/R 分子禁用「合理价值上沿」**（循环论证），取「最近有效阻力 ÷ 止损位」
33. **止损位 ≠ 保证成交价**；**以仓位为第一风控**，单一标的组合冲击 ≤ 1.5%
34. **同等期望回报下，永远选「可跟踪的风险」** —— 连续型下行优于二元型下行
35. **利好消息密度峰值 + 股价滞涨 = 派发特征**；筹码判断必须落到可查数据（基金家数 / 股东户数 / 北向 / 龙虎榜），**禁用「庄家吸筹 / 主力洗盘」等不可验证叙事**

### 跨境与口径

36. **A/H 溢价按部分收敛 haircut −20% ~ −25% 计入目标价**；H 股 IPO 价是发行折价 / 清算价 ≠ 内在价值；H 股递表本身即压制 A 股估值中枢，不必等发行
37. **港股必做汇率校验**：财报双口径倒推汇率，归母 × 汇率 ≈ 接口值
38. **关键数字必须标来源 + 时点 + 口径**；口径不可比时禁用比率（见 `methodology.md` §02 的 10 条口径陷阱）

### 前奏识别

39. **市值倍数 ÷ 利润倍数 > 1 是赚估值的钱**（叙事定价，安全边际框架不适用），< 1 才是赚利润的钱
40. **必须框架驱动扫描，不能新闻驱动**；「报表反差」须分辨真假（结构改善 vs 周期修复）；已排除方向与「出海 ≠ 前奏」见第 9 步

### 持仓与交付纪律

41. **买入成本是心理锚，市场不认。** 不以「回本」为决策依据。成本价本身不产生支撑 —— 产生支撑的是全体持有者的成本分布
42. **初筛结论必须显式声明「深度不足」**，不得与深度覆盖结论并列
43. **无验证点不出结论；验证点未通过不加仓**

## 二 · 陷阱对照（26 个）

| 陷阱 | 正解 |
|---|---|
| 把「跌了一半」当买入理由 | 参照系是公司自己的历史估值分位，不是跌幅 |
| 用近两年 PB 分位判低估 | 必须同时看十年 / 全历史分位（近两年中枢可能被主题行情抬高） |
| 把股东户数下降读作「筹码集中」 | 查年报「披露日前一个月末」户数，识别主题期涌入的散户余量 |
| 用产业资本减持价反推买点 | 减持价只证明「该价偏贵」，不证明「现价便宜」 |
| 引用卖方远期 PE 目标价 | 必须折现；净利率为负的公司给 50x+ PE 本身不成立 |
| 用 PE 给亏损公司估值 | 只看 PB 分位，并注意净资产缩水导致的「被动高估」 |
| 把 ETF 增持当主动看多 | 被动资金反映指数编制与申赎 |
| 忽略研发刚性 | 研发 ≈ 毛利额时，订单恢复也换不来利润弹性 |
| 用毛利率抬升直接推利润改善 | 先过 G2b 四项条件（含营收同比不为负、绝对毛利额同比为正） |
| 把买入成本当价值锚 | 成本不影响期望价；「回本」不是持有理由，用「期望价 ÷ 现价」重判 |
| 追已兑现的催化 | 要「催化未兑现」；题材落地后连板 / 政策落地后放量均属兑现完成 |
| 用「行业数据创新高」推个股利好 | 先验身份是否错配（收租方 / 渠道方收入由合同锁定，与行业景气脱钩） |
| 把初筛结论当深度结论 | 无完整覆盖必须显式声明「初筛，深度不足」，且不得作为加仓依据 |
| 忽略流动性下限与组合容量 | 自由流通过小则进出成本高、过大则无法被资金定价；须写明用的是哪一侧约束 |
| 用低 PE 选周期股 | 周期顶 PE 最低。改看 PB 分位 + 「上轮周期顶倍数 × 峰值盈利」再折现 |
| 把价格反弹当周期反转 | 先验供给是否出清（在建工程 ÷ 固定资产、开工率、库存天数）；供给不出清，一律按假复苏处理 |
| 用当期年化盈利给周期股估值 | 用中周期均价做正常化盈利再折现；底部、顶部、下行三段均禁用 PE |
| 把「剔除周期行业」误读为「周期股不可买」 | 该规则只作用于第 9 步前奏扫描，防价格修复型利润跳升污染 G1 / G2b |
| 「营业收入增加 → 股价上涨」/「盈利增加 → 股价自然上涨」 | 线性外推。须做单季环比双拆解、剔一次性、验扣非成色，并警惕高基数的下一季是增速陷阱 |
| 「利率上升 → 股价下跌」单链 | 未分流分子 / 分母、未给强度与时滞；同一变量对不同行业符号相反 |
| 由「跌破支撑线」反推基本面变坏 | 技术面只服务择时与风控；基本面变坏须由报表与传导链证明 |
| 「有主力吸筹 / 庄家在洗盘」 | 不可验证叙事。筹码判断须落到基金家数 / 股东户数 / 北向 / 龙虎榜 |
| 「公司回购 = 利好」 | 须查注销 vs 库存股、资金来源（自由现金 vs 借款）、回购价所处估值分位 |
| 「利好消息密集 → 买入」 | 信息密度峰值常是派发窗口；须看股价是否滞涨 + 筹码是否迁移（基金家数 / 户数） |
| 只看期望价、不算胜率 | 期望价可由「低概率 + 极端情景」单方面撑起。须同时给出胜率（情景价 ≥ 现价 × 1.15 的概率之和）与三档判定；胜率 < 30% 与期望价不达标**各自独立否决** |
| 用「机构一致预期偏乐观」代替胜率数字 | 定性表述不是测算。三情景价格、概率、概率之和 100% 必须显式列出 |

## 三 · 出清单前自检（38 项）

**逐项打勾。任何一项未打勾，结论不得发布 —— 不是「标注一下就行」。**

### 形态与口径

- [ ] 已按 15 类形态归类，**未使用任何禁用估值尺子**？
- [ ] 已确认跨年口径可比（会计政策切换、A/H、集团 vs 上市公司）？
- [ ] 涉及权益法收益时，**已剔除其偿债 / 分红能力**（纸面利润不产生现金）？
- [ ] 股本为摊薄后口径；分红率已用 DividendTTM 交叉验证？
- [ ] **同一份数据未被重复渲染成两个「维度」**（如行业地位饼图与营收结构柱图同源）——每个图表必须对应独立的数据切片？

### 环境与择时

- [ ] 宏观判断已分流**分子 / 分母**，并给出**强度与时滞**？
- [ ] 传导链已落到**可跟踪指标**（财务费用率 / 汇兑损益占比 / 出口收入占比…）？
- [ ] 未用「大势」替代个股尽调（未因大盘看多买入未过尺子的标的）？
- [ ] **有效阻力**由筹码密集区 / 前高识别（且该位置出现过放量滞涨），**不是合理价值上沿**？
- [ ] 筹码判断全部落到**可查数据**，未使用「庄家 / 主力」叙事？
- [ ] 涉及回购，已查**注销 vs 库存股 / 资金来源 / 回购价分位**？

### 周期

- [ ] 已区分「周期型 / 结构型」，并给出判据（**价差回落时利润还在不在**）？
- [ ] 周期定位五要素齐全，**尤其供给端**（在建工程 ÷ 固定资产、产能投放表、开工率）？
- [ ] 尺子已随周期位置切换，**底部 / 顶部 / 下行三段未使用 PE**？
- [ ] 是否把「PE 低」读作**卖出**信号，并已验分母持续性？
- [ ] 横向比较用**单位产能指标**而非绝对市值 / 绝对 PE？
- [ ] 退出按「卖在景气」四触发写死，**未用季报利润判拐点**？

### 利润

- [ ] 四条线（营收 / 归母 / 扣非 / 毛利率）单季环比已做双重拆解？
- [ ] 毛利率抬升型已过 **G2b 四项条件**（含绝对毛利额同比为正）？
- [ ] 一次性收入已剔出，并明示**剔后主营增速**？
- [ ] OCF 已与季节性拆开看，转负是否已定性为硬伤？
- [ ] 净利率 < 8% 已做毛利率敏感性 + 汇兑敞口？

### 筹码

- [ ] 筹码四件套已同看，股东户数已取**「披露日前一个月末」**口径？
- [ ] **资金进出趋势已给出**（近 20 日总资金 / 主力日度 + 分区间净额汇总 + 近 12 周主力净流入），周度极端值是否已截断并标注真实数值？
- [ ] 减持 / ETF 变动**未被当作买入信号**？
- [ ] 流动性双侧约束已显式说明用的是哪一侧？

### 算价

- [ ] PE 与 PB 分位**双窗口**（近两年 + 全历史）已同看，背离已解释？
- [ ] 目标价已**折现 + 概率加权**，情景概率之和 = 100%？
- [ ] **当前买入胜率已测算**（胜率数字 + 锁定门槛「情景价 ≥ 现价 × 1.15」+ 三档判定 + 对应仓位），未用「机构一致预期偏乐观」这类定性表述代替？
- [ ] 胜率与赔率已**双维校准** —— 未因「期望价够高」就跳过胜率判定（高期望价可由低概率极端情景撑起）？
- [ ] R/R 分子用的是「最近有效阻力」，**不是合理价值上沿**？
- [ ] 期望价 ÷ 现价 ≥ +15%？未达标是否已明确写「不买」而非「可以试试」？
- [ ] 横向 / 四象限图的**每根轴都全部可观测**（无负值 PE 之类导致大量样本被丢弃或造假的轴）？不可观测时是否已降维为单轴图？

### 闭环

- [ ] 已给出验证点（**指标 + 阈值 + 时间窗**三要素齐全）？
- [ ] 已给出退出判据（估值到位 / 逻辑破坏 / 价格破位 / 时间止损），**且未把成本价当锚**？

### 交付一致性（Phase 9.5 回查专项）

- [ ] 同一事实在**正文 / 括注 / 图内标注 / JS 数据集**四处一致（已跑 `verify_report.py`，且人读抽查散文里的旧数字）？
- [ ] **卡片数字与图表序列同源同口径**（如价格卡与价格图都用收盘价）；口径不同时已加注脚说明，未让读者误判为数据错误？
- [ ] 全篇**版本号统一**（无旧版 `v2.x` 残留）、**自检标题数 = 实际条目数**、**折现说明的算术已手算验过**？
