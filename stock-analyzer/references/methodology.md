# 个股分析方法论 · 完整流程速查（v2.3）

来源：工作区方法论文档《个股分析方法论-完整流程与红线-v2-20260930》
适用范围：A 股通用框架。本框架下所有产出的关键数字必须标注**来源 + 时点 + 口径**；概率与假设必须显式列出，不得以「一般认为」代替。

## 结论先行

分析一只股票不是「收集资料」，而是按固定顺序回答四个问题，并守住一条纪律。

1. **它赚的是什么钱？** 利润驱动还是估值驱动 —— 决定用哪把尺子
2. **现在贵不贵？** 跟自己历史分位比，不是跟跌幅比
3. **利润是真的吗？** 扣非、现金流、一次性、研发刚性
4. **谁在买、谁在卖？** 筹码结构决定「便宜」能不能兑现

**一条纪律**：任何跨年度目标价，必须**时间折现 + 概率加权**。未经这两道处理的目标价，一律视为卖方营销材料。
**一条收尾**：任何一份结论，必须附带**下一个验证点**（指标 + 阈值 + 时间窗）。没有验证点的结论是观点，不是分析。

## 01 · 使用顺序（不可颠倒）

顺序是方法的一部分。同一批数据，换个顺序读出来的结论可以完全相反。

| 步骤 | 名称 | 一句话判据 |
|---|---|---|
| 第 0 步 | 选对估值锚 | 先归类，再谈贵贱 |
| 第 1 步 | 价格位置 | 用分位，不用跌幅 |
| 第 2 步 | 盈利趋势 | 单季环比，双重拆解 |
| 第 3 步 | 盈利质量 | 剔干净还剩多少 |
| 第 4 步 | 资产负债表 | 亏损公司看净资产 |
| 第 5 步 | 行业横向 + 景气定位 | 看营收同比，不看亏损；赛道定五档（+2~−2） |
| 第 6 步 | 催化与事件传导 | 先验链条是否贯通 |
| 第 7 步 | 筹码与公司行为 | 便宜能不能兑现 |
| 第 8 步 | 估值与赔率 | 折现 + 概率加权 |
| 第 9 步 | 前奏态扫描 | 仅「找标的」时走 |
| 第 10 步 | 验证与退出 | 指标 + 阈值 + 时间窗 |

**三种典型颠倒失败**
1. 先算价再验形态 → 尺子错了，整个估值过程无意义
2. 先看筹码再验利润 → 把派发当吸筹（主动基金 21→2 家会被读成「机构还没进」）
3. 先看跌幅再查分位 → 把下跌当便宜，忽略「PE 低是因为盈利在顶」

**特殊形态插队**：周期类标的在「第 0 步」之后先走第 04 节《周期股专章》—— 周期股的尺子随周期位置切换，不做定位就定不了锚。

**两条横切层**（均不参与选股）：
- 第 05 节《环境与传导》：宏观只走传导链、大势只调仓位
- 第 08 节《技术面与时序》：只服务择时与风控

## 02 · 前置 · 口径陷阱（读表之前必须确认）

口径错了，后面所有比率都不可比，而且错得很隐蔽。

| 陷阱 | 机理 | 正确处理 |
|---|---|---|
| 会计政策切换造成跨年不可比 | 百货 2020 年由总额法改净额法，收入断崖式缩水但利润未变 | 跨 2020 年只有 ROE 与归母可直比；收入、毛利率一律不可直比 |
| A/H 双重上市口径混淆 | 同一权益两套价格，市值与 PB 会算出两个答案 | 报表口径与股价口径分开算；A/H 溢价单独处理 |
| 上市公司 ≠ 集团体系 | 集团口径含非上市资产，与上市公司报表不同源 | 只用上市公司披露口径；集团数据仅作背景 |
| 权益法投资收益不产生现金 | 如新希望持民生银行：账面有利润但不派现金（2025 现金股利仅 3.62 亿） | 报表利润照记，但禁止用于偿债、分红、回购能力测算 |
| 北交所代码已切换 | 旧代码段查询会漏标的 | 一律用新 920xxx 段 |
| 定增后 PB 下降是假象 | 净资产变大、股本变大，PB 机械走低 | 用摊薄后股本重算；同步看摊薄后 EPS 与 PE |
| 分红率口径不一 | 不同数据源的年报／TTM 口径混用 | 用 DividendTTM 交叉验证；TTM 亏损标 `n.m.`，不得填 0 |
| 高股息标的的前复权价失真 | 高分红使前复权价长期被压低，股息率被高估 | 高股息标的禁用前复权价，改市值口径；中期分红占比要跟「上年年报分红率」对比，不能跟本年 |

## 03 · 第 0 步 · 选对估值锚（15 类形态）

同一家公司用错尺子，结论可以完全相反。拿到标的先归类，再谈贵贱。

| 资产形态 | 主锚 | 禁用 | 实例 |
|---|---|---|---|
| 盈利稳定重资产 | ROE 校准 PB（戈登：合理 PB = ROE / r，r≈9%） | — | 武商集团 |
| 轻资产 | 正常化 PE + DDM + FCF 收益率三法收敛 | PB | 分众传媒 |
| 成熟制造 + 高分红 | DDM + 正常化 PE + 股息率反推 | PB | 宇通客车 |
| 强周期 | PB + 单位指标（头均市值等）+ 周期先行指标 | PE（峰值利润的反向指标） | 新希望 |
| 再投资出海（CXO） | PE + 在手订单 + 产能爬坡；扣非占比验成色 | 股息率 / DDM | 药明康德 |
| 资源周期 | 商品价格位置 + PE 分位 + 单位成本 + 量增 | 绝对 PE | 中国海油 / 中远海控 |
| 周期新材料 | 历史峰值盈利锚 + 三情景概率加权 + 红利覆盖全产能 | 一致预期远期 PE | 中国巨石 |
| 小盘成长 | PE + PS + 流动性折价 + 预测分歧度 | 单一盈利预测 | 康比特 |
| 薄利制造 / 出口链 | 终局 PE 折现 + 同业 PB/ROE 比值 + 净利率敏感性 | 同比增速、单一 PEG | 舒华体育 |
| 专业市场 / 园区运营 | 分部估值（高毛利收租业务单独×倍数）+ DDM + OCF 转正验证 | 并表 PE | 小商品城 |
| 亏损期制造 / 军工电子 | PB 双视角 + 同业横向（PS/PB）+ 订单节奏先行指标 | PE、一致预期远期 PE | 海格通信 |
| 银行 | PB ÷ ROE 匹配度 + 股息率 + 资产质量 | 单看 PB、PE | 苏农银行 |
| 寿险 | P/EV 主锚 + EV 驱动拆解 + 假设敏感性 | PE | 新华保险 |
| 未盈利创新药 | 管线 rNPV + 每股净现金 + 现金跑道 + 关键读出 | PE / PB / PS | 首药控股 |
| IP / 潮玩 | IP 瀑布拆解 + 存货周转 + 二手价 + 跨周期同业 PB 锚 | TTM PE、新 IP 同比 | 泡泡玛特 |

**「禁用」一栏是硬约束**：用禁用的尺子得出的结论，无论多合理都不采纳。典型 —— 用 PE 给亏损公司估值、用 PB 给轻资产公司估值。

表外形态：先回答「它的价值由什么现金流决定」，再选锚。

**注意**：「强周期 / 资源周期 / 周期新材料」三类不是拿到 PB 就能用 —— 须先做周期定位（价格 / 供给 / 需求 / 库存 / 成本曲线），见第 04 节。

## 04 · 周期股专章（跨行业形态，做周期标的必读）

周期不是「一个行业」，是**一种状态**。前面一节只给了周期三把尺子的名字，第 9 步又把周期当污染源剔除 —— 中间缺的那一层是**定位**。缺了定位，尺子一定会拿错，而周期股最贵的时点恰恰出现在 PE 最低的时候。

### 一 · 先分「周期型」还是「结构型」

判据只有一个：**价差回落时，利润还在不在。**

| 特征 | 周期型 | 结构型（含前奏） |
|---|---|---|
| 利润驱动 | 价差 / 加工差 / 商品价 | 份额 / 单位盈利 / 新市场 |
| 报表形态 | 单季跳升，前后无连续性 | 连续 ≥ 3 年单向抬升 |
| 反向验证 | 行业价格回落 → 利润消失 | 行业价格回落 → 利润仍在 |
| 走哪套框架 | 本节（周期框架） | 第 9 步前奏六道门槛 |

同一个标的可以同时是两者（如宇通客车 = 客车周期 + 出海结构改善，因此过得了前奏门槛）。判别动作是把价差还原到上轮周期均价，看利润还剩多少。

### 二 · 周期定位五要素（缺一不可）

1. **价格位置** —— 商品价 / 产品价 / 价差的历史分位（十年 + 上轮周期区间）。**看商品价，不看股价。**
2. **供给端（最关键）** —— 在建工程 ÷ 固定资产（资本开支周期位置）、未来 2–3 年产能投放表、行业开工率。
3. **需求端** —— 下游开工率、订单 / 库存周期、出口量。
4. **库存** —— 厂库 + 渠道 + 社会库存天数及其分位（同「库存使用比」思路，美玉米阈值 11%）。
5. **成本曲线位置** —— 单位成本在全行业成本曲线的分位。**位于曲线左端 = 周期底不死，这是能否穿越周期的唯一判据。**

**硬性判据**：五要素里「供给」不配合，价格反弹一律按**假复苏**处理。价格反弹 ≠ 产能出清。这一条最有杀伤力 —— 它把「跌幅足够大 + 价格反弹」这类最常见的周期股买入理由直接否掉。

### 三 · 四阶段 → 四把尺子（随位置切换）

| 阶段 | 特征 | 主锚 | 禁用 | 例 |
|---|---|---|---|---|
| ① 底部 / 亏损 | PE 失效或为负 | PB 分位 + 单位产能指标 + 重置成本 | PE | 新希望 |
| ② 复苏 | 价差正在修复 | 正常化盈利 PE（中周期均价）+ 单位成本 | 当期年化 PE | — |
| ③ 顶部 | 利润创历史峰值 | 上轮周期顶倍数 × 峰值盈利，再折现 | 低 PE 选股 | 中国巨石 |
| ④ 下行 | 价格下行、利润回落 | 现金成本覆盖 + 分红 + OCF 支撑 + PB 底 | 一致预期远期 PE | 中国海油 / 中远海控 |

四阶段共用一份报表，但每次只能用一把尺子。**PE 只在「复苏」段可用**，且须用中周期均价做正常化盈利；底部、顶部、下行三段一律禁用 PE。

### 四 · 分位指纹（周期版）与两条铁律

| PE 分位 | PB 分位 | 含义 | 动作 |
|---|---|---|---|
| 低 | 高 | 盈利在顶部 —— 周期股最危险的时点 | 不买；已持有减仓。涨得越多越要减 |
| 高 / 为负 | 低 | 盈利与股价双底 | 周期反转候选，但仍须先过「供给」要素 |
| 低 | 低 | 真便宜 | 仅在供给出清后成立，否则是价值陷阱 |
| 不适用（亏损） | 低 | 只看 PB 分位 | 注意净资产缩水造成的被动高估 |

**铁律一**：周期股「PE 低」是卖出信号，不是买入信号。低 PE 必须先验「分母能不能持续」。
**铁律二**：峰值盈利越确定，应给倍数越低。周期顶估值锚 = 上轮周期顶市场给的倍数 × 峰值盈利，再按 1/(1+WACC)^n 折现。用「可比公司当前 PE」给周期顶定价，等于把周期顶当成长股。

**口径提醒**：周期股的横向比较必须用**单位产能指标**（头均市值 / 吨产能市值 / 桶油市值 / 单箱运力市值），且与 PB 分位同时看 —— 绝对市值与绝对 PE 在周期股之间不可比。参考锚：生猪次线标的周期底 PB ≈ 1.5x、头均市值 1,500–2,000 元；现价在锚上沿即已无安全边际。

### 五 · 「剔除周期行业」的准确作用域

第 9 步附加门槛里的「剔除周期行业」**只作用于前奏态扫描**，目的是防价格修复型利润跳升污染 G1 / G2b。它**不适用于**已覆盖周期标的的分析，也**不等于**「周期股不可买」—— 两者混淆会导致把「筛不出」误读成「不能买」。

实证：某次扫描中 G2b 原始值最高的几只全部出局（贵金属、炼化、工业金属），利润增幅榜前列（+910% / +2501% / +1344%）亦全部出局。原因不是「涨得少」，而是它们的利润来自价差修复，不可持续。

### 六 · 周期股退出：卖在景气，不在季报

| 触发 | 判据 |
|---|---|
| 估值到位 | 达到「上轮周期顶倍数 × 峰值盈利」的折现值 → 分批减 |
| 供给重启 | 行业在建工程 ÷ 固定资产回升、新产能公告密集 → 先于价格见顶减仓 |
| 价格分位 | 商品价进入历史 80% 分位以上 |
| 单位盈利转弱 | 单位成本优势收窄 / 价差连续两季回落 |

**禁用：用季报利润判断周期拐点。** 季报是滞后的确认，不是先行信号 —— 等季报看到利润下滑时，价格下行往往已走了 1–2 个季度。先行的是价格、开工率与在建工程。

风险型态：周期股的下行多为**连续型（可跟踪）**，不是二元型 → 同等期望回报下优先选它；但正因可跟踪，不能用「等破位再走」代替主动减仓 —— 可跳空标的的硬止损属假性风控，正解是以仓位为第一风控。

### 七 · 须额外取的四组数据（常规七维不覆盖）

1. 商品 / 产品价格序列及其十年分位（月频）
2. 行业产能与在建工程：在建工程 ÷ 固定资产、未来 2–3 年投放节奏表
3. 开工率 / 库存天数：一律取**行业级**，不取公司级（公司开工率会被自身订单结构掩盖）
4. 成本曲线位置：单位成本在全行业的排位

## 05 · 环境与传导：大势 + 宏观（自上而下的唯一入口）

**为什么单开一节**：自上而下与自下而上必须分工 —— **大势只决定仓位，宏观只通过「传导链」进入模型**。最常见的亏钱方式，就是拿宏观结论直接买个股。

### 三条纪律：把「利率升 → 股价跌」这类单链升级为可验证的传导

1. **必须分流「分子 / 分母」** —— 利率上行杀的是分母（贴现率），若同期盈利上行，股价可以涨。只写「利率升 → 股价跌」等于没分析。
2. **必须给强度与时滞** —— 链条上每一环都要能说出量级与时间；说不出，就是不知道。
3. **必须可验证** —— 传导结论要落到可跟踪指标（财务费用率、汇兑损益占利润比、出口收入占比…）。**无法落到利润表的宏观判断，不得作为买入理由。**

### ① 大势：只定仓位环境，不选定标的

| 观察项 | 取什么 | 用途（与「不用途」） |
|---|---|---|
| 指数估值分位 | 沪深 300 / 中证 500 的 PE、PB 十年分位 | 决定总仓位上限；**不决定买哪只** |
| 流动性 / 银根 | 两市成交额、两融余额、新发基金份额 | 决定小市值与主题标的有没有定价环境 |
| 情绪（仅作反向参考） | 破净率、股债性价比（ERP）、涨跌停家数比 | 只在极端值作反向参考，**不作交易信号** |

**硬约束**：大势只调仓位，不替代个股尽调。不得因「大盘要涨」买入未过尺子的标的。

### ② 宏观传导矩阵：同一变量对不同行业符号相反

**宏观变量没有普适符号。** 使用前先查这张表，再落到具体公司。

| 变量 | 传导通道 | 受损 | 受益 | 时滞 |
|---|---|---|---|---|
| 利率 ↑ | 分母（贴现率）+ 分子（财务费用）；同时抽走社会游资 | 高估值成长、高负债地产 / 基建 | 银行（息差）、保险（再投资） | 1–2 季度 |
| 税收 ↑ | 分子（税后利润） | 无税收优惠、高税率制造 | 免税行业；减税期符号反转 | 当期 |
| 本币升值 | 分子（收入折算 + 汇兑损益） | 出口链 / 薄利制造 | 进口成本型（航空燃油、纸浆、大豆压榨） | 1–2 季度 |
| 银根松 | 分母（估值 + 流动性溢价） | — | 小盘成长、主题 | 数周–数月 |
| 通胀 ↑ | 分子（成本 vs 提价能力） | 无提价权的中下游 | 资源 / 上游 | 1–2 季度 |
| 经济周期 | 分子（量、价） | 见第 04 节周期定位五要素 + 四阶段尺子切换 | 同左 | 见该节 |
| 产业政策 | 分子（收入 vs 利润率） | 被约束行业 | 被扶持行业 | — |

**本节与第 5b 步（景气定位）的分工**：本节回答「**哪些宏观变量正在改变该行业的分子或分母**」（变量视角）；第 5b 步回答「**赛道整体现在处在周期的哪一档、该如何调整情景概率**」（状态视角）。先看变量有没有在动，再定档位。

**政策给的是收入，不是利润率。** 必须落到「落在哪个板块、毛利多少」；拿不到毛利率提升证据的政策利好，给收入不给利润。

**与周期专章的分工**：第 04 节解决「产品价格处在周期什么位置」；本节解决「哪些宏观变量正在改变该行业的分子或分母」。两者不重叠。

### ③ 身份错配审查（唯一能救回宏观结论的一步）

先验「事件 → 行业 → 公司利润表」传导链是否贯通；核心是识别**身份错配** —— 收租方 / 平台方 / 渠道方 ≠ 交易方，收入由合同锁定、与行业景气脱钩。

- 最有力的反证是「行业数据创新高而公司核心利润下滑」
- 利好要定**时滞**：商户订单 → 出租率 → 租金重定价需 12–18 个月，远慢于筹码派发
- 「事件前已有正面报道、事件日仍大跌」= **时序证伪**，说明已被定价，不是利好
- **β 级利好不能对冲 α 级利空**

### ④ 「小环境」经典七项如何接回七维

| 经典条目 | 在 v2 的对应位置 | 处理 |
|---|---|---|
| 营业收入 / 盈利 | 第 2、3 维（趋势、质量） | 「营业收入增加 → 股价上涨」是错的 |
| 固定资产 | 第 4 维（资产负债表） | 已覆盖；周期标的同时看「在建工程 ÷ 固定资产」 |
| 类似公司情况 | 第 5 维（行业横向 + 景气定位） | 已覆盖；看营收同比，不看亏损绝对值；并定赛道景气档位 |
| 品牌的价值 | 第 0 步选锚（轻资产 / IP 形态） | 已覆盖；IP 须做瀑布拆解 + 存货周转 + 二手价 |
| 新产品 | 第 6 维（催化）；创新药 rNPV | 催化须 6–12 个月内可见 |
| 公司回购 | 第 7 维（公司行为） | 见「公司回购三查」 |
| 「股价上涨」的归因 | 第 8 步（估值与赔率） | 拆成「利润倍数 × 估值倍数」，不许直接归因「盈利增加」 |

### ⑤ 公司回购三查

| 查什么 | 为什么 |
|---|---|
| **注销** 还是 **库存股** | 只有注销才真正减少股本、增厚每股价值；划入库存股可日后再卖出，价值中性甚至为负 |
| **资金来源** | 自由现金流回购 = 股东回报；**借款回购 = 加杠杆托股价**，与「高分红 + 借款增 + 经营现金流为负」同族警报 |
| **回购价 vs 估值分位** | 在估值分位高位回购 = 向卖方输送价值；回购价与减持价同源，只证明「该价偏贵」，不构成买点 |

与分红口径联动：回购金额可计入股东回报，但**不得与分红重复计入**；分母一律用摊薄后股本。

## 06 · 第 1–7 步 · 七维尽调

### 第 1 步 · 价格位置 —— 用分位，不用跌幅

- 用**前复权收盘价**自算近两年 / 近五年区间分位；记录横盘时长
- 标出关键高低点的**时间与成因**，区分「业绩顶」与「主题泡沫顶」—— 两者的修复路径完全不同（主题顶靠筹码出清，业绩顶靠利润回升）
- ✘ 禁用：把「跌了一半」当买入理由。参照系是公司自己的历史估值分位，不是跌幅
- ✘ 禁用：「板块内最便宜」—— 相对便宜是陷阱，不是安全边际

### 第 2 步 · 盈利趋势 —— 看单季环比，不看同比

- 年度 + 单季四条线同看：营收 / 归母 / 扣非 / 毛利率。高增长标的必做「半年环比 + 单季环比」双重拆解
- **核心判据**：连续两季营收同比与扣非同向恶化 ⇒ 未磨底。季节性证伪必须用同一年度的 Q2→Q3 环比，不能跨年比
- **毛利率抬升型标的必做结构改善净贡献（门槛 G2b）**：
  ```
  净贡献 = 毛利率同比 − 销售费用率同比 − 管理费用率同比
  ```
  须四项同时满足：① 结果 > 0；② 营收同比不为负；③ 中高档 / 高端产品销量增速 ≥ 30%；④ 绝对毛利额同比为正
- **高基数的下一季是增速陷阱**：先剔掉一次性收入，再问「主营增速还剩多少」（例：配套房产一次性贡献 5.8 亿利润总额 → 下一季是高基数）
- 反例：某公司毛利率 +10.66pct，销售费用率却 +8.05pct，净利持平 —— 只看毛利率会直接误判

### 第 3 步 · 盈利质量 —— 剔干净了还剩多少

- 扣非 / 归母比；一次性收入单独剔出，问「剔掉后主营增速还剩多少」
- **经营性现金流由正转负 = 质量硬伤**，必须与季节性因素拆开看
- **利润成色好 ≠ 经营未恶化**：扣非 / 归母占比高、但扣非增速低，两项同时成立时，「成色好」恰恰说明**经营性利润本身停滞**
- **研发刚性陷阱**：研发投入 ≈ 毛利额时，即使订单恢复，利润弹性也被显著削弱（例：毛利 10.42 亿 vs 研发 9.28 亿，研发占营收 21.49%）
- 净利率 < 8% 的薄利公司，必做**毛利率敏感性 + 汇兑敞口**（毛利率降 1pct → 利润降约 14%）
- 政策主题要问落在哪个板块、毛利多少 —— **政策给收入不给利润率**

### 第 4 步 · 资产负债表 —— 尤其看亏损公司

- 有息负债变化、现金短债比、OCF 是否连续为负
- 亏损公司必须警惕「**净资产缩水**」：PB 的分母自己变小，会制造「被动高估」的估值陷阱
- 「高分红 + 借款增 + 存货增 + 经营现金流为负」四并存需警惕 —— 但**命中 2/4 不构成高危**，须逐项核对，不得机械扣分

### 第 5 步 · 行业横向 + 景气定位 —— 判「行业性」还是「公司自身」，并定「赛道在哪一档」

两件事同做：横向比同业、纵向定景气。只做横向会漏掉赛道方向 —— 同业都在涨可能是行业景气上行，也可能只是集体反弹后一起回落。

**5a 行业横向**

- 同子板块取 ≥ 3 家 + 跨子板块取 ≥ 3 家对照
- **判决指标是「营收同比」，不是亏损绝对值。** 亏损收窄 / 营收转正 = 行业复苏已落地；亏损扩大且营收仍负 = 问题在自身
- 行业复苏但公司未跟上 ⇒ β 反弹拿不到，须下调至「恢复最慢」定价

**5b 景气定位（五档刻度，直接喂给第 8 步的情景概率）**

> 一句话原理：**行业 β 是公司情景概率的输入项，不是背景介绍。** 同一个公司基本面，赛道在 +2 与在 −2，乐观/悲观情景的合理概率完全不同。忽略赛道方向，等于默认「行业永远中性」，这是系统性的概率误配。

| 档位 | 名称 | 判据（须挂可查先行指标） | 对情景概率的作用 |
|---|---|---|---|
| **+2** | 繁荣 | 量价齐升 / 供不应求 / 产能满载 / 行业利润创新高 | 乐观概率上调，但**这是卖出区不是买入区** |
| **+1** | 复苏 | 需求回暖 / 价格企稳回升 / 开工率上行 / 同业营收同比转正 | 乐观概率上调 |
| **0** | 平稳 | 供需大体平衡，无明确方向性驱动 | **不作行业调整**（基准态，公司 α 主导） |
| **−1** | 放缓 | 增速放缓 / 价格见顶 / 库存天数抬升 / 新增产能开始投放 | 中性略偏悲观（利好兑现即退出） |
| **−2** | 衰退 | 需求收缩 / 价格下行 / 产能出清未完成 / 公司营收仍负 | 悲观概率上调（是否见底看**供给端**配合） |

**先行指标清单**（按行业挂，每档至少说出 1–2 个真实数字）：商品价十年分位 / 产能利用率 / 在建工程÷固定资产 / 库存天数及分位 / 同业营收同比 / 开工率 / 订单能见度。

**两条防滥用规则**（缺了刻度就退化成「编故事」）：

1. **每一档必须挂可查到的先行指标才算数**。说不出来一律判 0（平稳），不得凭印象给 +1 / +2。
2. **档位是「当前已发生的事实」，不是预测**。只描述现在处在哪一档，不预测未来会走到哪档；对未来路径的判断本身就体现在情景概率的分配里。

**与周期专章的分工**（读第 04 节时对照）：周期专章解决「**产品价格**处在周期什么位置、该用哪把尺子」（个股粒度）；本节解决「**赛道整体**景气在哪一档、该如何调整情景概率」（行业粒度）。两者结论必须一致；不一致时以周期专章为准（它更细且有四阶段尺子）。

**景气 × 估值的组合读法**（判「胜率为什么高 / 低」）：

| 景气档位 | 估值分位 | 读法 |
|---|---|---|
| +1 / +2 | 低 | **戴维斯双击候选** —— 胜率最有利的位置 |
| +1 / +2 | 高 | 景气已被定价 —— 涨的是估值，风险在倍数 |
| 0 | 低 | 纯 α 机会 —— 靠公司自身兑现，无赛道顺风 |
| −1 / −2 | 高 | **最危险** —— 景气下行 + 估值贵，戴维斯双杀 |
| −1 / −2 | 低 | 困境反转候选 —— 但须先验「供给是否出清」，供给不配合一律按假复苏 |

### 第 6 步 · 催化与事件传导 —— 先验链条，再看利好

- **宏观利好 ≠ 个股利好。** 必须逐段验证「事件 → 行业 → 公司利润表」传导链是否贯通，缺一段即证伪
- 核心是识别**身份错配**：收租方 / 平台方 / 渠道方 ≠ 交易方，收入由合同锁定，与行业景气脱钩
- **利好必须定时滞。β 级利好不能对冲 α 级利空。**
- **时序证伪**：「事件前已有正面报道、事件日仍大跌」= 利好已被定价
- **已兑现的催化不追。** 要「催化未兑现」的标的；已兑现的（题材落地、政策落地、订单公告后的连板）不追
- **催化窗口要求：6–12 个月内可见。** 更远的催化不进当期定价，只可用于「跟踪」不可用于「买入理由」

### 第 7 步 · 筹码与公司行为 —— 便宜能不能兑现

- **筹码四件套同看**：主动基金家数、股东户数、北向持股、ETF 是否退出十大流通股东
- 典型派发结构：主动基金 21→2 家 + 户数 +37% + 北向减仓
- ⚠️ **股东户数下降不能直接读作「筹码集中」**：须查年报「**披露日前一个月末**」户数，识别主题期涌入的散户余量
- **被动 ETF 增减持 = 指数编制与申赎，不构成主动看多**
- **产业资本减持价只证明「减持价偏贵」，不证明「现价便宜」，不可反推买点。** 减持从来不是买入信号
- **公司回购三查**（见第 05 节 ⑤）
- **利好消息密度峰值是派发窗口**：公告 / 券商强推最密集时，配合「股价滞涨 + 主动基金家数减少」，判为派发
- **卖方评级 vs 买方持仓背离时，信后者。** 对卖方一致推荐保持独立否决权
- **流动性是双侧约束**：自由流通太小（< 30 亿）流动性差、进出成本高；太大（> 100 亿）则少量资金无法定价。须显式说明用的是哪一侧

## 07 · 第 8 步 · 估值与赔率：把结论算成一个价

### ① 分位指纹（先看病灶在哪）

**标口径前必做：反算验证。** 行情软件同一时点常并列给出三个 PE —— 动态 / 静态 / 另一口径，三者对应的净利基数完全不同。**验证方法：市值 ÷ PE = 隐含净利，与哪个口径的净利润对得上，就叫哪个口径。**

实例（小商品城 2026-09-30，市值 607.58 亿）：

| 行情软件标注 | 读数 | 反算隐含净利 | 实际口径 |
|---|---|---|---|
| 动态 PE | 13.53x | 44.91 亿 | 近 12 个月（含 2026H1 一次性房产结转） |
| 静态 PE | 15.35x | 39.58 亿 | 2025 年 |
| 另一口径 | 14.45x | 42.05 亿 | 2025 年报归母 |

**标错口径不叫标错数** —— 13.53 的算法本身没错，错在把它标成「TTM」。**但更严重的问题是**：若动态 PE 的隐含利润含大额一次性项目，不得据此得出「历史最低分位 → 便宜」。本例中，13.53x 靠的是含 12 亿一次性房产结转的利润，而同一份报告另一节正在论证「剔除一次性后经常性利润增速已停滞」——**两段互相拆台**。此时应同时给出剔除后的经常性 PE（本例约 16.9x）。

**口径不可混用**：若分位取自 A 序列（本例理杏仁扣非 TTM 序列，读数 12.46x、分位 0.14%）、绝对倍数取自 B 序列（本例动态 13.53x），**两者不可并列比较**。分位（相对位置）可用，绝对倍数不可 —— 必须在口径说明中显式区分。

| PE 分位 | PB 分位 | 读法 |
|---|---|---|
| 低 | 低 | 真便宜 —— 继续查基本面是否在恶化 |
| 低 | 高 | 盈利在顶 —— 分母（利润）处于历史高位，PE 低是假象 |
| 高 | 低 | 盈利与股价双底 —— 周期反转候选 |
| 99%+ | 0% 附近 | 盈利崩塌 —— 教科书级陷阱（例：PE 分位 99.67% / PB 分位 3.22%） |

**双窗口必做**：同看「近两年分位」与「十年 / 全历史分位」。背离即说明近期中枢被主题行情抬高（例：近两年 15% vs 十年 53%）。**只看近两年，会把「PE 低 + PB 高」的盈利在顶误判为便宜。**
亏损公司无 PE，**只看 PB 分位**；轻资产公司的 PB 分位只跟自己历史比，不跨行业比。

**估值分位四象限**：横轴 PE 历史分位、纵轴 PB 历史分位，30% 为门槛。
- 左下（双低）= 真便宜
- 左上（PE 低 PB 高）= 盈利在顶
- 右下 = 盈利崩塌
- 仅看 PE 分位单轴，会把后两类全部误判为价值

### ② 折现 + 概率加权（唯一合法的目标价算法）

```
折现价 = 目标市值 / (1 + WACC)^n     // n 为年数，WACC 常用 12%
期望价 = Σ(情景价 × 情景概率)         // 概率之和 = 100%
```

**判据**：即便完全接受卖方最乐观假设并折现，若结果 ≈ 现价 → 现价无安全边际。
**买入门槛为 期望价 / 现价 ≥ +15%**，达不到就是「不买」，而不是「有点空间可以试试」。

时间折现的实战校验：某卖方目标价 13.58 元 —— 实为 2028 年 6.24 亿利润 × 54x PE，**未折现**；补折现（WACC 12%，因子 0.774）后 10.51 ≈ 现价，安全边际归零。同一方法在多个标的上各修正过一次。

#### ②附 · 卖方目标价三面检验

卖方目标价是报告里**最容易制造「便宜感」的数字**：一个未折现的 19.84 元配上现价 11.08 元，读者第一反应就是「涨 79%，很便宜」。引用它之前必须过三面，三面结果都要写进报告：

| 检验 | 做法 | 不做的后果 |
|---|---|---|
| ① 折现后可比 | 名义价 × 折现因子（12%/3 年 = 0.7118），得与现价同口径的可比价 | 未折现价与现价直接比，安全边际被系统性放大 |
| ② 多平台口径交叉 | 至少 2–3 个来源（富途 / 腾讯舆情 / 券商研报原文），列出差异 | 单一来源可能取到最高值；口径分歧本身即信息 |
| ③ 与自身情景对照 | 折现后卖方区间与自己的三情景折现价并排 | 看不出「卖方最乐观 ≈ 我方乐观」，误以为卖方更乐观 |

**三个必须写出的结论**：
1. **折现后的卖方区间 vs 现价** —— 名义 +79% 折现后往往只剩 +13%~27%
2. **卖方目标价高，通常高在 PE 倍数而非盈利预测** —— 若券商自己的盈利预测与你的中性情景接近，必须点明「倍数分歧」才是真分歧；若券商用「公司历史估值均值」定倍数，要追问该均值是否形成于盈利低位（是则方向反了）
3. **卖方评级系统性偏乐观的行业事实**（建议写出）—— A 股研报 90%+ 给「买入/增持」，卖出评级近零；A 股券商目标价 6 个月后平均偏离实际股价约 32%、12 个月约 47%（海外 12 个月目标价兑现率不足 50%）。**目标价应读作「卖方立场声明」，不是价格预测。**

**卖方动向必查**：近 3–6 个月是「上调预测」还是「下调预测但维持评级」。若券商下调盈利预测的同时维持「强推/增持」且目标价下移，说明**评级已滞后于其自身模型**；报告若用「过去 12 个月均值」，就已滞后于这轮下调。

#### ③ 跨节数据一致性三查（交付前人工必做）

报告分节写作，同一事实容易在不同节以不同口径出现，机器脚本抓不到。交付前逐项人工核对：

| 查什么 | 具体做法 | 真实事故 |
|---|---|---|
| **口径查** | 同一收入 / 利润项在同比、环比两处出现时，须各自标明对比基准 | 数贸中心交付结转：一处写「Q2 环比 +23.9% 主要来自交付」，另一处写「同比增量 25.69 亿中交付贡献 12 亿」——读者易误读为「一笔贡献两笔增量」，实为同一收入项的两种呈现 |
| **加总查** | 所有分部 / 分项表加总须等于并表总额；差额单列「其他 / 内部抵消」或注明未披露 | 分部营收加总 100.83 亿 vs 并表 102.82 亿，差 1.99 亿未说明，读者自行加总对不上会怀疑全表 |
| **假设查** | 情景假设隐含的增长率若高于报告别处论证的趋势，必须正面拆解该情景由哪几块拼出 | 中性情景 62.6 亿隐含 3 年 CAGR 14.2%，而正文论证「扣非 Q2 同比仅 +0.6%、增速停滞」——须说明 62.6 亿 = 经常性个位数增长 + 已签约项目结转 + 新业务减亏，不依赖经常性利润加速 |

**为什么必须人工**：verify_report.py 只能查标签配平、计数、算术等式；口径、加总、假设的一致性属语义层面，必须靠人逐节比对。

**实例**（小商品城 2026-09）：富途均值 19.84 / 腾讯舆情 17.69 / 两份券商研报 18.00 与 17.86。**顶部指标卡取中位 18.00 元**（若取最高的 19.84 元，等于一边在正文批判卖方乐观、一边用最高值放大便宜感，立场自相矛盾）。折现后 12.59–14.12 元。而**卖方自己的 2028E 归母预测 61–63.5 亿，与本报告中性情景 62.6 亿几乎一致**；分歧全在 PE：券商给 19.6–20x（依据「历史均值 24x」），本报告给 13x。历史均值形成于盈利低位，用它定高位利润的倍数，方向就是反的。同期两家券商均在**下调** 26–28 年预测。

**三情景概率加权示例**（⚠️ 独立演示案例，数字与模板示例**不是同一家**）：悲观 8.00 元 × 25%，中性 10.50 元 × 45%，乐观 13.00 元 × 30% → 期望价 = 13×30% + 10.5×45% + 8×25% = **10.63 元**，较现价 10.00 仅 +6.3%，低于 +15% 买入门槛 ⇒ 结论是「不买」。概率加权的作用，正是把模糊的「还不错」变成一个可以拒绝的数字。

### ②b 当前买入胜率

期望价回答「平均能赚多少」，**胜率回答「这一把赢面多大」**。两者缺一不可 —— 高期望价可以完全由低概率 + 极端情景撑起，那不是胜率，是彩票。

**定义：胜率 = 满足「情景价 ≥ 现价 × 1.15」的情景概率之和。** 门槛沿用 +15% 买入尺子，保持全流程一致。预期收益不足 +15% 的情景，在纪律上按「不赢」计。

**三档判定：**

| 胜率 | 判定 | 动作 |
|---|---|---|
| ≥ 50% | 高胜率 —— 即便按最可能的中性情景也算得过来 | 达到期望价/现价门槛即可分批建仓 |
| 30% – 50% | 中等偏博弈 —— 需要乐观情景才能赢，靠赔率补 | 只在期望价 / 现价 ≥ +25% 时介入，且首仓减半 |
| < 30% | 低胜率 —— 典型「赌重估」 | 不买。与买入门槛判定独立，任一不过即否决 |

**沿用上例自检**（仍是那组演示数字，非模板示例）：悲观 8.00（−20%，未达门槛）× 25%，中性 10.50（+5%，未达门槛）× 45%，乐观 13.00（+30%，达标）× 30%。
→ **胜率 = 30%（仅乐观情景达标）**，期望价 10.63 对现价仅 +6.3% < +15%。**两个判定同时不过 ⇒ 双重否决，结论是「不买」。**

⚠️ 注意门槛是 **+15%** 而非「涨了就算赢」：本例中性情景 10.50 虽然相对现价上涨 5%，但**未达 +15% 门槛，不计入胜率**。这是最容易算错的一步 —— 若误按「正收益即算赢」，本例胜率会被算成 75%，恰好把「不买」的结论翻转成「可买」。

**期望价与胜率的关系（用于校准，不是替代）：**

```
期望价 / 现价 − 1 ≥ 胜率 × 乐观收益率 − (1 − 胜率) × 悲观损失率
```

期望价高但胜率低 ⇒ 期望靠尾部情景撑起 ⇒ 提高赔率要求或直接用仓位控制。**不能说「期望价够高所以胜率不重要」。**

**②c 行业景气 → 情景概率的联动**

> 不做这一步 = 默认「行业永远中性」。同一个公司基本面，赛道在 +2 与在 −2，乐观/悲观情景的合理概率完全不同。
> 这是**胜率被系统性高估的最常见来源** —— 只看公司、不看赛道，相当于给周期下行行业的公司配了上行的概率。

第 5b 步定出的景气档位是概率的**前置输入**，必须显式落到概率分配：

| 景气档位 | 对概率的作用 | 上限 |
|---|---|---|
| +2 繁荣 | 乐观概率上调 | 单情景 ≤ +10pct |
| +1 复苏 | 乐观概率上调 | 单情景 ≤ +10pct |
| 0 平稳 | 不作调整（基准态） | — |
| −1 放缓 | 悲观或中性概率上调 | 单情景 ≤ +10pct |
| −2 衰退 | 悲观概率上调 | 单情景 ≤ +10pct |

**硬约束：**

- **单情景调整幅度上限 ±10pct** —— 防止把行业叙事当赌注加倍器
- **必须写明调整依据**：哪一档、挂的是哪个先行指标、调了哪个情景几个百分点。「行业不错所以调高乐观」不是依据
- **必须复盘原始概率**：报告要能看出「公司自身基本面 → 基准概率」再「叠加景气调整 → 最终概率」，两步分开，读者可复核
- **+1/+2 ≠ 买入**：景气高位时乐观概率可上调，但**估值分位若已高，仍是卖出区**。概率上调只改期望值，不改变「贵」这个事实

**必写的四句话**（缺一句即视为未测算）：
1. 三情景的价格、概率、概率之和 = 100%
2. **景气档位 = ?（+2~−2）**，挂的先行指标是什么，概率因此调了多少
3. 胜率 = X%（锁定门槛：情景价 ≥ 现价 × 1.15）
4. 胜率对应的仓位建议（高 / 中 / 低三档）

**与风控的接口**：胜率 < 30% 时，即便决定小仓位参与，也须按「跳空 −25%~−30%」定价仓位，使单一标的组合冲击 ≤ 1.5% —— 低胜率标的的仓位不是「多少合适」，而是「能不能承受归零」。

**禁止**：用「机构一致预期偏乐观」这类定性表述代替胜率数字；三情景概率必须显式列出，不得以「一般认为」代替。

**胜率 × 赔率定位（四象限）**：横轴胜率（< 30% / ≥ 50%），纵轴期望价 / 现价（< +15% / ≥ +15%）。
- **高胜率 + 高赔率** → 可建仓
- **高胜率 + 低赔率** → 等更好价位，不追
- **低胜率 + 高赔率** → 首仓减半，按跳空风险定仓位上限
- **低胜率 + 低赔率** → 否决，两个判定都不过

### ③ 赔率与风控

- **R/R 分子禁用「合理价值上沿」（循环论证）**，取「最近有效阻力 ÷ 止损位」
- **止损位 ≠ 保证成交价**：可跳空标的的硬止损属「假性风控」（两日可 −15.9%；反垄断、商誉、H 股发行均为跳空型事件）
- **正解 = 以仓位为第一风控**：按跳空 −25% ~ −30% 定价，使单一标的组合冲击 ≤ 1.5%，用「**事件前主动减仓**」替代「事件后止损」
- **同等期望回报下，永远选「可跟踪的风险」** —— 连续型下行优于二元型下行
- **A/H 与港股专项**：A/H 溢价按「部分收敛 haircut −20% ~ −25%」计入目标价；H 股 IPO 价是发行折价 / 清算价 ≠ 内在价值；**H 股递表本身即压制 A 股估值中枢**，不必等发行落地。港股必做**汇率校验**：用财报双口径倒推汇率，归母 × 汇率 ≈ 接口值
- **终值威胁按时间维度分层采纳**：不进当期 EPS，但**封顶退出倍数**（例：CPO 威胁把退出 PE 上限从 24–26x 压到 18–21x —— 市场先压倍数、后见盈利）

## 08 · 技术面与时序：只服务择时与风控

技术分析在本框架里**只有两个合法用途**：① 确定买点区域；② 确定止损位与 R/R 分子。**不得用于选股、不得用于估值、不得由「跌破支撑」反推基本面变坏。** 越过这条线，就会与主锚（估值分位）互相打架。

### ① 各工具的合法接口

| 工具 | 能提供什么 | 接在本框架的哪一步 |
|---|---|---|
| 趋势线 / 均线（50、200 日） | 当前位置处在长期趋势的哪一侧 | 第 1 步「价格位置」的辅助（主判据仍是分位） |
| 支撑 / 阻力 | 止损位与 R/R 分子 | 第 8 步③ 风控 |
| 头肩顶 / 底（双肩图） | 趋势转折的确认，本质滞后 | 仅作「减仓时机」的二次确认，**不作买入依据** |
| 成交量 | 验证突破真伪（放量滞涨 / 缩量突破） | 第 7 步筹码；派发判别的观察工具 |
| 布林带（20 日, 2σ） | 现价在波动区间中的相对位置（%B）与带宽（波动率状态） | 买点区域的细化 —— 触及下轨 = 短期超卖区，可作「分批建仓的第一档」触发条件；**不得单独作买入依据**（超卖可以更超卖） |

**布林带的口径**：中轨 = MA20，上下轨 = MA20 ± 2×总体标准差（20 日）。%B = (现价 − 下轨) ÷ (上轨 − 下轨)，取值 0–100%；%B < 20% 为接近下轨（超卖区），%B > 80% 为接近上轨（超买区）。带宽 = (上轨 − 下轨) ÷ 中轨，反映波动率 —— 带宽极度收窄常预示变盘，放宽则趋势已启动。**必须写明取的是「总体标准差」还是「样本标准差」**（二者差约 2.6%，会影响上下轨小数位）。

### ② 「有效阻力」如何识别

1. **筹码密集区** —— 前期成交额最大的价格带（套牢盘集中处）。这是**最硬**的阻力
2. **前高 / 前低** —— 最近一次明显转折的高点。「能否穿越上次的高点」是趋势强弱的直接判据：穿不过 → 市场对该价位的看法改变 → 股价逐级滑落
3. **整数关口** —— 只作次要参考，**不得单独作为阻力**

**有效性判据**：该位置附近是否出现过**放量滞涨**。出现过才算有效阻力；没出现过，它只是心理位。

R/R 分子仍禁用「合理价值上沿」。分子用最近有效阻力，分母用止损位；**两者都必须是从价格图上读出的数字，不能来自估值模型**。

### ③ 支撑 / 阻力的心理机制 ——「成本锚定」的市场版

| 筹码状态 | 心理 | 行为后果 |
|---|---|---|
| 套牢、未割 | 「回本就卖」 | 反弹到成本区 → 抛压增加 |
| 已割肉 | 「记忆犹新，不敢重新入场」 | 同一价位买盘减少 |
| 两者叠加 | 原「低价」概念被粉碎 | 原支撑位 → 新阻力位（供求双杀） |

**推论：股价跌到「你的成本价」不产生任何支撑。** 产生支撑的是全体持有者的成本分布。你的成本若落在密集成交区上方，那个位置对你的意义是阻力，不是解套点 —— 所以「等回本再走」在结构上就是错的时点。

### ④ 信息密度峰值 = 派发窗口

流传最广的「吸货 → 公开推荐 → 派发 → 找接盘者」叙事**不可验证，不得作为结论**；但其中可验证的内核是「信息密度」与「筹码迁移」的时序关系：

| 阶段 | 可观测特征 | 动作 |
|---|---|---|
| 吸货 | 成交温和放大、股价慢涨、公开层面无利好、主动基金家数增加 | 可跟踪，但只能事后确认，不构成买入理由 |
| 拉抬 + 公开推荐 | 券商强推密集、媒体连篇、董事长更替 / 大订单 / 新产品等好消息密集、涨停放量 | **报警 —— 这是派发窗口，不是买入窗口** |
| 派发 | 主动基金家数减少、股东户数上升、北向减仓、利好后股价不涨 | 减仓 |

**判据：利好消息密度峰值 + 股价滞涨 = 派发特征。**
量化观察项：主动基金家数 / 股东户数 / 北向持股 / 涨停次日表现。

⚠️ **剔除项**：不得使用「庄家吸筹」「主力洗盘」等不可验证叙事下结论 —— 所有筹码判断必须落到可查数据（基金家数、股东户数、北向、龙虎榜）。

## 09 · 第 9 步 · 前奏态识别（进阶：只在「找标的」时走）

**首要判据**：市值倍数 ÷ 利润倍数 —— > 1 是赚估值的钱（叙事定价，安全边际框架不适用）；< 1 才是赚利润的钱。

### 维度

| 维度 | 内容 |
|---|---|
| 4 条结构性共性 | ① 起点被行业叙事判过死刑（不是「跌得多」）；② 出现单位盈利能力更高的新市场；③ 报表反差；④ 筹码空白（主动公募 0~1 家 + 户数降 + 自由流通 ≤ 100 亿） |
| 三层信号（按可得时间） | T−12~6 组织 / 渠道断点（**跨行业空降总经理是最早信号**）→ T−6~3 报表反差 → T−3~0 估值筹码 |
| 真假反差判别 | 真 = 结构改善（连续三年单向抬升）；假 = 周期修复（价差 / 加工差驱动，单季跳升） |
| 已排除方向 | 中药（销售费用率 20–45% 吞没毛利）、出版传媒（行情后段、估值先行利润未动）。**出海 ≠ 前奏** —— 出海公司汇兑损失可观，整条链「收入增、利润降」，必须过利润弹性门槛 |
| 两条最容易犯的错 | ① 股价滞后基本面 6–12 个月，启动前常有一次最后下跌；② 能搜到的一律已进入定价 ⇒ **必须框架驱动扫描，不能新闻驱动** |

### 前奏态六道门槛总表（权威定义，须照抄不得简写）

| 门槛 | 定义 | 为什么必要 |
|---|---|---|
| G1 | 归母增速 ÷ 收入增速 ≥ 3x，且两者同为正 | 报表反差的最低形式 |
| G1b | 归母增速绝对值 ≥ 15% | 防分母过小（收入 +0.59% / 归母 +1.91%，比值 3.2 轻松过线但无意义） |
| G2 | 毛利率同比 ≥ +2pct | 结构改善 |
| G2b | 毛利率同比 − 销售费用率同比 − 管理费用率同比 > 0，且营收同比不为负，且中高档 / 高端产品销量增速 ≥ 30%，且绝对毛利额同比为正 | 防毛利率被费用吃回（毛利率 +10.66pct 却净利持平） |
| G3 | PE、PB 历史分位双 < 30%（近两年窗口判定 + 全历史窗口校验背离） | 只看近两年会把「PE 低 + PB 高 = 盈利在顶」误判为便宜 |
| G4 | 自由流通 ≤ 100 亿 | 筹码可被少量资金定价 |
| 附加 | 上年同期归母 ≥ 1.2 亿（防低基数）、扣非 / 归母 ≥ 70%、市值 ≥ 30 亿、剔除周期行业（作用域仅本步扫描） | — |

**G2b 副则**：凡「毛利率抬升型」标的必再验绝对毛利额同比；「中高档 / 高端产品销量增速」列为消费品扫描的**标准字段**（非可选）。
**G1b 副则**：比值门槛与绝对增速门槛必须同时使用，单用比值会在低基数上选出伪信号。

### 筛选漏斗实绩（39 行业穷举，示例）

全 A 股 5,163 只经六道门槛逐级过滤 → G1 后 875 只 → +G2/G1b 后 121 只 → 规模与估值初筛 64 只 → G2b 后 63 只 → 剔周期 / 低基数 / 扣非差后 14 只 → G3+G4 后 4 只，**淘汰率 99.92%**。

注意：G2b 那级几乎未淘汰（64→63）—— **G2b 是必要条件而非筛选主力**，真正的杀伤来自「剔周期 / 低基数 / 扣非差」（63→14）与估值筹码三关（14→4）。「利润增幅榜前几名」几乎全部倒在 G2b 与「真假反差」判别上。

## 10 · 第 10 步 · 验证与退出（闭环）

前九步产出的是「买不买」。第 10 步产出的是「买完之后怎么办」—— **缺了这一步，分析只是观点**。

### ① 验证点：三要素缺一不可

任何结论必须附带**指标 + 阈值 + 时间窗**。只有指标没有阈值，等于没写。

示例格式：
- 「26Q3 OCF 能否转正，且不低于上年 Q3 的 68.39 亿量级（10 月底）」
- 「26Q3 营收同比能否转正 + 扣非环比是否收窄 + OCF 是否连续第二季改善（10 月底）」
- 「26Q3 报告中确认会计政策变更对管理费用率跨期可比性的影响（口径未知项）」

验证点要写成「**可判真假的一句话**」，不写「关注三季度业绩」。

### ② 退出判据：四类触发，事先写死

| 类型 | 触发条件 | 实例 |
|---|---|---|
| 估值到位 | 触及概率加权目标价上沿 → 分批减 1/3 ~ 1/2 | 8.20–9.00 分批减 |
| 逻辑破坏 | 支撑买入的核心变量被证伪 → 不问盈亏直接退出 | 扣非 < 14 亿；26Q3 OCF 未转正 |
| 价格破位 | 跌破事先定义的关键低点 → 加速减 / 清仓 | 破 10.68 加速减、破 10.0 无条件清仓 |
| 时间止损 | 约定窗口内未兑现催化 → 重新评估占用成本 | 收敛斜率 −0.83pct/年 → 关闭一半缺口需 3.6 年，不应线性折现 |

### ③ 减仓时机优先于止损价位

- **事件前主动减仓 > 事件后止损。** 可跳空事件（反垄断、商誉减值、H 股发行、解禁、业绩说明会）执行「事件前减 1/3–1/2」，把不可控的跳空风险转成可控的仓位风险
- **业绩说明会是明确的可执行窗口**：会前减仓、会后按三问结果决定余仓（分红与现金流规划 / 核心利润下滑是让利还是客户流失 / 新业务收益确认节奏）
- **时间炸弹要列成清单并前置**：解禁股数与时点、转债到期与转股价、控股股东 EB 换股价、质押股数 —— 这些都是**可提前排期的减仓时点**，不是新闻

### ④ 🔴 成本锚定效应 —— 实战中最烧钱的一条

**买入成本是心理锚，市场不认。** 凡是把「回本」当决策依据的分析，都已被锚定污染。

机理示例：成本 13 → 回本需 +18.7%，而成本对应 PE 14.6x vs 当前市场只给 12.3x ⇒ 回本必须靠估值修复而非业绩增长，容错空间极小。

**正确表述**：「折现期望价 12.15 < 成本 13 → 数学上不支持死等回本」；同时「12.15 对现价仅 +11.0%，低于 +15% 买入尺子 → 不构成加仓」。两个结论各自独立，都由现价与期望价得出，**与成本无关**。

## 11 · 专项口径（三行业）

### 创新药

- 单品高增长必拆「**销量 × 价格**」—— 价格跌幅 > 70% 即为**以价换量**，不是真实需求扩张
- **集采风险三触发**：同靶点获批数 ≥ 8 款 / 是否入基药目录 / 该代际渗透率 > 85%（例：三代 EGFR 渗透 88%、9 款竞品）
- **利润质量三扣**：政府补助占比 / 研发占比是否下降 / 未决诉讼是否计提。**已盈利创新药用 EV/PE**
- **rNPV 参数**：已获批 100% × 70% 商业化折扣；NDA 75%（补资料 ×80%）；III 期 60%；I 期 10%；稳态净利率 20%、成熟 PE 22x、WACC 12%
- **注册路径**：「首批国产」必查 NDA 受理排序 + 补资料通知；卖断已上市产品分成 = 资金压力信号；破发状态下解禁形成「首发价天花板」。竞品商业推广方是最佳交叉验证源

### 银行股

- 核心指标 **PB / ROE 比值**（农商行中位锚 0.0517）；当期与前瞻一起看；息差要拆来源
- 🔴 **破净 ≠ 便宜**，必看 PB 历史分位。**PE 分位 99.9% + PB 分位 0% = 盈利崩塌**，是陷阱不是价值
- 农商行合理价用「ROE ÷ 目标 PB 比值」倒推（例：PB 0.48 / ROE 12.46% → 合理价 4.84，配置 10%）

### 农产品 / 农业

- **分三层**：全球 vs 中国（常反向）/ 分品种 / 当期 vs 滞后
- **厄尔尼诺年大豆单产可能 +5%**（反直觉）。面积与单产拆开看；库存使用比阈值：美玉米 11%
- 数据源：FAO 分项、USDA WASDE（9 月实测最关键）、NOAA
- **生猪链条**：能繁存栏变化须用 PSY 折算实际供给（PSY 23+ 时能繁 −10% 实际供给仅缩 5–6%）

## 12 · 组合与选股流程

### ① 组合层面

- **砍相关性，不砍数量。** 每个风险篮子只留最强那只。判据：**会不会因同一条消息一起跌**
- **风险贡献 = 权重 × 最坏跌幅**，不是权重本身。风险性质决定仓位：收获 / 成长兑现 / 周期博弈 / 困境反转 / 价值陷阱，五类给不同上限
- **压力测试分母用总资产，不用股票仓位** —— 用股票仓位做分母会系统性高估承受力
- 组合风险由**前三大仓位**主导。对比不同数量的方案时，**必须拉到同等股票仓位**再比，否则不可比

### ② 主动选股四步（问「主动找哪些值得入手」时）

```
① 先锁尺子（全程不换）
   = 概率加权期望价 / 现价 ≥ +15%
   + 盈利质量可验证
   + 增长未透支
   + 催化剂 6–12 个月内可见
   + 筹码未派发

② 扫量化池
   = PE_TTM 十年分位 < 30 + PB 分位 < 30 + ROE > 12
   （港股加市值 > 300 亿）

③ 逐条过尺子，宁缺毋滥
   剔除必须写清客观理由 —— 禁用「超目标价」「已分析过」
   对卖方一致推荐保持独立否决权

④ 无完整覆盖必须显式声明「初筛结论，深度不足」
   候选池必须独立于覆盖进度 —— 反可得性偏误：
   不因为某只已经分析过就排除，也不因为某只没看过就优先
```
