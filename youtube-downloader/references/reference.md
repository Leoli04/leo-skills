# YouTube 下载参数速查 / Quick Reference

## 字幕语言代码 / Subtitle Language Codes

| 语言 Language | 代码 Code |
|---|---|
| 简体中文 Simplified Chinese | `zh-Hans` `zh-CN` `zh` |
| 繁体中文 Traditional Chinese | `zh-Hant` `zh-TW` `zh-HK` |
| 英文 English | `en` `en-US` `en-GB` |
| 日文 Japanese | `ja` |
| 韩文 Korean | `ko` |
| 法文 French | `fr` |
| 德文 German | `de` |
| 西班牙文 Spanish | `es` |

## 质量选项 / Quality Options

| 参数 | 说明 |
|---|---|
| `best` | 最高质量（默认） |
| `1080` | 1080p（Full HD） |
| `720` | 720p（HD） |
| `480` | 480p（SD） |
| `360` | 360p |
| `worst` | 最低质量 |

## 常见代理地址格式 / Common Proxy Formats

```
http://127.0.0.1:7890
socks5://127.0.0.1:1080
```
